# AI に操作させる試験（使い捨ての試作）

Qwen3.5-2B が、頼まれた事務作業を、道具を使いながら何手も続けて最後までこなせるか（Claude Cowork に近い使い方）を確かめた。

- `Invoke-Agent.ps1`: 問題ごとに作業用フォルダ（`%TEMP%\agent-probe\<id>`）を作り、AI に1手ずつ道具を選ばせる（JSON の形を指定）。道具は作業用フォルダの中だけで動き、消す道具は無い。画面は本物の窓ではなく、スクリプトの中のまね（入力欄とボタン）。
- `tasks.json`: 12問（ファイルの仕分け・報告書・CSV の抜き出し・画面への入力・名簿の照合・あいまいな頼みで人に聞くか）と採点の条件。
- 使い方: `Invoke-Agent.ps1 -Model qwen3.5-2b-q4_k_m.gguf [-Assist] [-Official] [-Think] [-Ids a,b]`

## 結果（2026-11-05、VM、llama.cpp b12063 x64、`-c 8192 --cache-ram 0 -np 1`、最大15手）

| 条件 | できた | 内訳 |
|---|---|---|
| 素のまま（温度0） | 0/4（4問目で試作の不具合で停止） | 仕分け 0/2、報告 0/2 |
| 工夫あり（`-Assist`: 最初にフォルダの中身を見せる・同じ手の繰り返しを知らせる。`-Official`: 公式の推奨設定で答えにゆらぎ） | 3/12 | 仕分け 0/2、報告 0/2、CSV 0/2、画面 1/2、照合 0/2、人に聞く 2/2 |

できた3問は、どれも「人に聞いて止まった」もの。そのうち画面の1問と整理の1問は、正しい理由で聞いたのではなく、作業に行き詰まって聞いていた。

## 間違え方

- 読んだ結果を次の手に使えない。名簿を2つ読んだあと、同じ2つを交互に読み続けて15手を使い切った。
- 道具の欄を取り違える。`set_field` で欄の名前（path）を空にして値だけ入れる、`write` の中身を path に入れる、など。
- やっていないのに終わったと報告する（素のままの画面入力: 1欄だけ入れて finish）。
- 無いファイルや外の場所を作り出す（`/mnt/data/申请书.pdf`、中国語の字）。ゆらぎを入れた設定で目立った。
- 同じ手を繰り返す。「同じ手です」と知らせても止まらない。

## 分かったこと

2B のモデルに、作業の段取りを任せる（何手も続けて自分で決めさせる）のは無理。1手ずつの判断（分類 8/10、画面の判断 8/10、抜き出し 29〜30/32）はできるので、ふじキュンでは、段取りはマクロ（人が作る手順）が持ち、AI には決まった1つの問い（どれに当たるか・どうするか・何が書いてあるか）だけを任せる形にする。
