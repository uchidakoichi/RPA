起動・環境

Q. fujikyun.bat をダブルクリックしても画面が出ない／すぐ消える

  • fujikyun.bat・fujikyun.ps1・fujikyun_ja.json・fujikyun_commands.json・fujikyun_templates.json の5つが 同じフォルダ にあるか確認してください。
  • RAW 表示からメモ帳に貼り付けて作った場合は、ファイル名の拡張子（.txt が付いていないか）と、JSON を UTF-8 で保存したか を確認してください。
  • 組織の設定で PowerShell の実行そのものが止められていることがあります。その場合は情報システム担当の方に、Windows PowerShell 5.1 でスクリプトを実行できるか確認してください（fujikyun.bat はその1回の起動にだけ -ExecutionPolicy Bypass を付けています。グループポリシーで決められている場合はポリシーが優先されます）。

Q. 「起動できなかったキュン…」と出る

メッセージの内容を確認してください。よくある原因は次のとおりです。

メッセージの内容どうする
is not the expected UTF-8 file など、JSON（fujikyun_ja.json など）が読めないJSON を UTF-8 で保存し直します（Shift_JIS で保存すると読めません）
ファイルが見つからない5つのファイルが同じフォルダにあるか確認します

Q. ボタンなどが gui.schedule のような英字の名前で表示される

fujikyun_ja.json が古いままです。fujikyun.ps1 と同じ時点の fujikyun_ja.json に置き換えてください（起動時にもお知らせが出ます）。

Q. 起動に時間がかかる

ログの「⏱ 起動にかかった時間」に内訳が出ます。PowerShell 自体の起動に数秒かかる端末があります。画像でクリック・記録は、最初に使うときだけ準備に数秒かかります。

Q. 「一時ファイルへの自動保存に失敗」と出る

ふじキュンを置いたフォルダに書き込めません。デスクトップ、ドキュメント、C:\RPA作業\ など、自分が書き込めるフォルダに移してください。

Q. 「PowerShellの言語モード」が FullLanguage 以外になっている

組織の AppLocker / WDAC の設定で、PowerShell が制限モードで動いています。ふじキュンは FullLanguage でないと動かない機能が多いので、情報システム担当の方に確認してください。

Q. 環境チェックで「C#のその場コンパイル」が NG になる

画像でクリック（CLICK_IMG）と記録（⏺）が使えません。それ以外の機能は使えます。ボタンは CLICK_NAME（名前）や CLICK_TEXT（文字）で押せることが多いです。

音・アラーム

Q. アラームが鳴らない

  • パソコンの音量やミュートを確認してください。
  • 実行の操作の ［□ アラーム音］ のチェックが外れていると、異常停止時に鳴りません（🔔 のテストは常に鳴ります）。
  • アラーム音のファイル C:\Windows\Media\Alarm01.wav があるか、環境チェックで確認できます。ファイルが無いときは Windows の警告音で知らせ、ログに理由が出ます。

入力がうまくいかない

Q. 文字が入力されない／別の場所に入る

  • 入力先の欄に カーソルが入っているか 確認してください。ロボットは「いまカーソルがある場所」に貼り付けます。
  • 画面が表示される前に入力している可能性があります。前に WAIT（例 1000）を入れるか、「間隔」を増やしてください。
  • 途中で別のウィンドウが前に出る環境では、実行の操作の ［□ 毎ステップ前面化］ を ON にします。

Q. 前の文字が残ったまま、後ろに追加される

TEXT・CSV は「貼り付け」なので、元の文字の後ろに入ります。直前に KEY ^a（全選択）を入れると上書きになります。

Q. KEY で文字を送ると、ひらがなや変な文字になる

日本語入力（IME）が ON だと、KEY で送った英字が変換されてしまいます。文字の入力は TEXT を使ってください（クリップボード経由なので IME の影響を受けません）。

Q. 「+」や「%」を KEY で送りたい

SendKeys では +（Shift）^（Ctrl）%（Alt）などは特別な意味があります。{+} {%} のように { } で囲みます。文字として入力したいだけなら TEXT を使うのが簡単です。

Q. Excel に貼り付けると日付や数字の形が変わる

Excel が自動で書式を変えています。先に Excel 側で、貼り付ける列のセルの書式を「文字列」にしておいてください（先頭の 0 が消える番号なども同じです）。

ウィンドウ・クリック

Q. 「対象ウィンドウが見つからない」で止まる

  • タイトルは 完全一致 → 先頭一致 → 末尾一致 で探します。途中の文字だけでは見つかりません。
  • ［🔍 一覧］で実際のタイトルを確認し、変わらない先頭部分か末尾部分を指定してください。
  • 例: 「台帳.xlsx - Excel」→ Excel（末尾）または 台帳.xlsx（先頭）

Q. CLICK_NAME で「見つからなかった」と出る

  • 画面のボタンの文字と 完全に同じ か確認してください（全角・半角、スペースも区別します）。
  • 独自の描画をしている画面や、Citrix・リモートデスクトップの中では名前が取れません。CLICK_TEXT（文字で）・CLICK_IMG（画像で）・CLICK_POS（座標で）を使ってください。

Q. CLICK_NAME で「押下(Invoke)に対応していないオブジェクト」と出る

名前は見つかりましたが、押せない部品です（入力欄やラベルなど）。ボタンのほか、チェックボックス・選択肢・展開できる項目は押せます。入力欄にカーソルを置きたいときは、Tab での移動か CLICK_POS を使います。

Q. CLICK_POS の位置がずれる

  • ウィンドウの位置・大きさが変わると座標がずれます。対象ウィンドウを 最大化 して、その状態で座標を取り直してください。
  • ディスプレイの拡大率（125%など）を変えた場合も取り直してください。

Q. CLICK_IMG が見つけてくれない

  • しきい値を 0.9 → 0.85 → 0.8 と少しずつ下げてみてください。
  • 見本画像に背景が多く入っていると失敗しやすいです。ボタンの特徴的な部分だけを小さめに切り取り直してください。
  • Windows のテーマ・色・拡大率が、画像を切り取ったときと同じか確認してください。

CSV・差し込み

Q. CSV が文字化けする

文字コードを［文字コード自動判定］から Shift_JIS や UTF-8 に切り替えてみてください。

Q. {{氏名}} がそのまま入力される

CSV の見出しと文字が違います（スペース、全角・半角の違いなど）。ログに「差し込み {{…}} が何か分からなかった」と出ます。［＋ 差し込みを追加 ▼］から選ぶと確実です。見出しが無いCSVなら {{1}} のように列番号で指定します。

Q. CSVを使わずに同じ作業を何回かくり返したい

「CSVの行数＝回数」として使えます。1列だけのCSV（例: 見出し「回」、1〜10の10行）を作って読み込めば10回くり返します（テンプレート「一定間隔で画面を記録」を参照）。CSV を読み込まずに実行すると1回だけ実行します。

Q. 最初の1回だけ（または最後だけ）実行したい手順がある

グループ を作り、実行タイミングを「最初の1行だけ」または「最後の1行だけ」にします。アプリの起動やログインは「最初だけ」、保存や終了は「最後だけ」にすると便利です。

実行・結果

Q. 実行を止めたい

実行中はロボットが入力先の画面を前に出しているので、次のどれかで止めます。

  • Esc を約1秒長押し（どの画面が前にあっても止まります）
  • ふじキュンの画面をクリックしてから Esc か［⏹ 停止］
  • 確認ポイントの表示中は、そのまま［⏹ 停止］か Esc

マクロの中の KEY {ESC} は一瞬押すだけなので、長押し停止には反応しません。

Q. 途中から再開したい

［↓ 実行結果CSV］で、どの行まで「完了」になったかを確認し、開始行 をその次の行番号にして実行します。

Q. エラーになった行だけやり直したい

［↓ エラー行をCSV保存］→ fujikyun_error_list.csv を Excel で直す → そのファイルを CSV 欄で読み込んで実行します。

  • このCSVには「元データ行No」列があるので、「1行目は見出し」が ON なら {{ROW}} は元のCSVの行番号になります（Excel のセル番地などもずれません）。
  • WINDOW_CHECK の SKIP 以外のエラー（WINDOW_CHECK の STOP、タイムアウト、ウィンドウが見つからない、クリック失敗など）は 実行そのものが止まるので、その後ろの行は処理されていません。元のCSVで 開始行 を続きの行にして実行してください。

Q. 実行結果CSV とエラー行CSV の違いは？

実行結果CSVエラー行CSV
入る行処理したすべての行エラー・SKIP の行だけ
追加される列COPY・RECORD の値、証跡ファイル、実行結果、備考など元データ行No、エラー内容、発生日時
主な用途結果の確認・台帳づくり直して再実行

どちらも ▶実行 を押すたびにリセットされます。必要なら実行のたびに保存してください。

保存・共有

Q. 起動すると「前回の編集中データが見つかった」と出る

前回、本番ファイルに保存せずに終了しました。［はい］で続きから編集できます。［いいえ］なら本番ファイルを読み込み、一時ファイルは fujikyun_macros_temp_discarded_日時.json に控えとして残ります（退避できなかったときは、上書きされないように一時ファイルの内容を開きます）。

Q. 起動すると「本番ファイルを読み込めなかった」と出る

fujikyun_macros.json が壊れているか、ほかの人やソフトが開いていて読めませんでした。元のファイルは fujikyun_macros_broken_日時.json に控えを取ってあり、本番ファイルもそのまま残っています。いったんふじキュンを閉じて開き直すか、1つ前の版 fujikyun_macros_backup.json を［📥 取込］で戻してください。この状態で本番ファイルに保存しようとすると、上書きしてよいか確認が出ます。

Q. RUN で「コマンドで特別な意味を持つ文字が入っていた」と出て、行が飛ばされた

RUN の差し込みに " & | < > ^ % や改行が入っていると、データがコマンドとして実行されてしまう危険があるので、その行は実行しません。PowerShell を呼ぶ RUN（PDF にする・ZIP にするなどのテンプレート）では、' ` ` $ ; ( ) { } も同じ扱いです（資料(1).xlsx` のような名前も止まります）。フォルダ名やファイル名にこれらの文字を使わないようにCSVを直してから、エラー行CSVで再実行してください。

Q. マクロを同僚に渡したい

［📤 書出］で macro_export\マクロ名.json（同じ名前があれば マクロ名 (2).json）ができるので、それを渡して相手に［📥 取込］してもらいます。CLICK_IMG を使っている場合は rpa_images フォルダも一緒に渡してください。

Q. 別のパソコンに引っ越したい

ふじキュンのフォルダごとコピーすれば、マクロ・画像・見本CSVがそのまま使えます。画像のパスを相対パス（rpa_images\…）にしておくと、フォルダの場所が変わっても動きます。

使い方のアイデア

Q. 入力以外にどんなことができる？

  • 照会＋証跡: 番号を順番に照会して画面を保存（監査・点検用）
  • 値の収集: たくさんの Excel から同じセルの値を集めて一覧化
  • チェック: 「該当なし」を SKIP させて、結果CSVで未登録の一覧を作る
  • 検算: 電卓で計算し直して、台帳の金額と見比べる
  • ファイル整理: RUN から Windows のコマンドを呼んで、フォルダ作成・ファイル名変更を一括で
  • 定型文の量産: 差し込みで、お知らせ文・メール下書き・Word 文書を人数分

くわしくは テンプレート解説 の「応用・発見のヒント」を見てください。

Q. 安全に使うコツは？

  1. 最初は 照会（見るだけ） のマクロから始める
  2. 必ず 1件だけ（開始行＝終了行）で試す
  3. 登録・送信の前に 確認ポイント（CONFIRM） を入れる
  4. SCREENSHOT で証跡を残す
  5. 止め方（Esc を約1秒長押し、またはふじキュンの画面で Esc／⏹）を覚えておく

変数・繰り返し・分岐

Q. 繰り返しが終わらない／「上限の○回に達した」で止まった

「条件のあいだくり返す」の条件が、いつまでも満たされたままになっています。条件に使っている変数が、繰り返しの中で変わっているか確認してください（［📊 変数］パネルで見られます）。回数が分かっている場合は「決めた回数くり返す」を使うと安全です。

Q. 変数の値がおかしい／何が入っているか知りたい

実行の操作の ［📊 変数］ を押すと、実行中の変数・繰り返しの回数・この行のCSVの値がリアルタイムで表示されます（COPY で入れた値も変数として出ます）。一時停止（⏸）しながら確認すると分かりやすいです。

Q. {{$名前}} が空っぽになる

その変数にまだ値が入っていません（入れるコマンドより前で使っている、変数名のつづりが違う など）。［＋ 差し込みを追加 ▼］から選ぶと、マクロの中で使っている変数名が一覧に出ます。

Q. Excelのセルを読む・書くで失敗する

  • Excel が入っているか［🩺 環境チェック］で確認してください。
  • 書き込むブックは閉じておいてください（ほかで開いていると「書き込めない」エラーになります）。
  • シートは名前か番号（1＝1枚目）で、セル番地は A1 の形で指定します。

Q. エラー時の処理を入れたのに止まった

WINDOW_CHECK（ウィンドウ検知）の STOP（緊急停止）と、⏹ 停止・Esc による停止は、わざと止める操作なので受け止めません。また「エラーのとき」の中で起きたエラーは、外側のエラー時の処理（なければ停止）に回ります。

記録・スケジュール・文字認識・メール

Q. 記録した操作を再生すると、文字が入らない／違う場所をクリックする

記録はたたき台です。日本語の入力は記録できないので、記録された「日本語を入力していた」コメントの場所に TEXT か CSV を入れてください。座標クリック（CLICK_POS）はウィンドウの位置や大きさが変わるとずれるので、CLICK_NAME（名前）・CLICK_TEXT（文字）・CLICK_IMG（画像）に置き換えると安定します。

Q. 予定の時刻になっても実行されない

  • ［⏰ 予定］で「✅ 有効」になっているか確認してください。
  • ふじキュンを開いていないときは、［🗓 Windowsに登録］していないと動きません。
  • ふじキュンが自分で実行するのは、予定の時刻から10分以内だけです。それより後にふじキュンを開いても、その日は実行しません。
  • ダイアログ（編集画面など）が開いていると、閉じるまで待ちます。
  • PCがスリープ・ログオフ・画面ロック中だと動きません。

Q. ［🗓 Windowsに登録］で失敗する

組織のポリシーでタスクスケジューラへの登録が止められていることがあります。ログに出たメッセージと、［🩺 環境チェック］の「Windowsのタスク スケジューラ」の行を確認してください。登録できない場合も、ふじキュンを開いておけば予定どおりに実行できます。

Q. 文字認識（OCR）で読み取れない・違う文字になる

  • ［🩺 環境チェック］で「文字認識」が OK か確認してください（日本語の文字認識が必要です）。
  • 範囲を「範囲を指定」にして、読みたい部分だけを小さく囲むと正確になります。
  • 文字が小さすぎる・背景と色が近い画面は苦手です。画面の拡大率を上げると改善することがあります。

Q. メールが送れない

  • Outlook: ［🩺 環境チェック］で Outlook があるか確認してください。すぐ送信にすると、Outlook のセキュリティの確認が出ることがあります。
  • mailto: 既定のメールアプリが設定されていないと開きません。
