ふじキュン♡のRPAマクロビルダー 操作マニュアル

Windows だけで動く RPA（パソコン作業の自動化）ツールです。インストール不要で、fujikyun_rpa_builder.hta をダブルクリックすると起動します。ネットワークにはつながりません。

3. 基本の考え方：CSVの1行＝1回

ふじキュンは マクロ（手順）を、CSVの行の数だけくり返します。

CSV                        マクロ
氏名,電話番号               ① SWITCH 入力画面へ
見本 太郎,000-0000-0001  →  ② CSV 1列目を貼付
試験 花子,000-0000-0002  →  ③ KEY  Tab
練習 一郎,000-0000-0003  →  ④ CSV 2列目を貼付
                            ⑤ KEY  Enter
  • 「1行目は見出し」にチェックがあると、1行目は見出しとして扱い、2行目からくり返します（初期値はチェックあり）。
  • CSV を読み込まずに実行すると、マクロを 1回だけ 実行します（CSV コマンドは空欄扱い）。
  • 文字コードは自動判定（UTF-8 → だめなら Shift_JIS）です。Excel で「CSV（コンマ区切り）」で保存したファイルもそのまま読めます。
  • " は Excel と同じく、値の 先頭 にあるときだけ囲み文字として扱います（12"モニタ のような値はそのまま文字として読みます）。" の閉じ忘れや、列の数がほかと違う行があると、読み込み時にログで知らせます。
  • 途中の 空の行 は行番号を数えたまま残し、実行のときは飛ばします（{{ROW}} や Excel の行がずれません）。

4. マクロの作成と編集

作り方は3通り

  1. ［📚 テンプレート］から作る（おすすめ）: お手本を選んで［✨ 作る］。見本CSVも自動で読み込まれます。
  2. ［＋ 新規］で空のマクロから作る: 「追加」の行のボタンでコマンドを足していきます。
  3. ［📥 取込］で同僚が書き出したマクロを取り込む（13章）。

ブロックの操作

したいこと操作
選ぶ1回クリック（青枠になります）。次に追加するコマンドは 選んだブロックの後ろ に入ります
編集するダブルクリック、右端の ✎、または Enter
削除する右端の ✕、または Delete。グループは「中身ごと削除」か「枠だけ解除」を選べます
並べ替えるドラッグ＆ドロップ（青い線の位置に入ります）、または ▲▼（Alt+↑↓）
複製する⧉ 複製（Ctrl+D）。グループなら中身ごと複製します
一時的に止める⊘ 無効化（Ctrl+/）。薄く表示され、実行時は飛ばされます。もう一度押すと元に戻ります
元に戻す↩️（Ctrl+Z）／ やり直し ↪️（Ctrl+Y）。履歴▼から好きな時点にも戻れます（最大30件）

グループ

GROUP を追加すると「グループ開始〜グループ終了」がセットで入ります。

  • 中のブロックは字下げされ、左の ▼/▶ で折りたためます。
  • グループ開始を無効化すると、グループの中身がまるごと飛ばされます。
  • 実行タイミング を設定できます。
    • 毎行（ふつう）
    • 最初の1行だけ: アプリの起動、ログイン、画面を開くなどの「準備」に
    • 最後の1行だけ: 保存、閉じるなどの「後片付け」に

5. コマンド一覧

「値（val）」はマクロファイル（JSON）に保存される形です。編集ダイアログでは項目ごとに入力できるので、書式を覚える必要はありません。

入力

コマンド値動き
KEY キー送信送るキー（例 {TAB}）キーボード操作を送ります。書き方は 7章
TEXT 文字列貼付文字列（差し込み可）クリップボード経由で貼り付けます（Ctrl+V）。日本語入力がONでも化けません
CSV CSV列を貼付列番号（1始まり）いま処理中の行の、指定した列の値を貼り付けます。空欄なら何もしません
COPY_SAVE 値をコピーして記録項目名いま選ばれている文字を Ctrl+C でコピーして記録します。記録した値は 実行結果CSV の列 になり、あとの TEXT で {{COPY:項目名}} として貼り付けられます

💡 TEXT・CSV は「貼り付け」なので、入力欄にもともと文字があると後ろに追加されます。上書きしたいときは直前に KEY ^a（全選択）を入れます。

待つ・確かめる

コマンド値動き
WAIT 待機ミリ秒（1000＝1秒）指定時間待ちます
WAIT_FOR ウィンドウ出現待ちタイトル,押すキー,タイムアウト秒指定タイトルのウィンドウが出るまで1秒ごとに見張り、出たらキーを押して次へ。時間切れならアラームを鳴らして停止します
IF 条件分岐タイトル,押すキー,モードそのウィンドウが いま 出ているかを確認。出ていたらキーを押して、モードに従います。出ていなければ何もせず次へ
CONFIRM 確認ポイントメッセージ（差し込み可）ロボットを止めてメッセージを表示し、人の判断を待ちます

IF のモード:

モード動き使いどころ
STOPアラームを鳴らして緊急停止想定外のエラー
SKIPこの行を打ち切り、エラー行として記録して次の行へ「該当なし」など、飛ばせばよいもの
CONTINUEキーを押してそのまま続行ときどき出るお知らせ・上書き確認などを閉じる

CONFIRM のボタン:

  • ▶ 続行: 対象ウィンドウに戻って続きを実行
  • ⏭ この行をスキップ: この行を打ち切って次の行へ
  • ⏹ 停止: 実行をやめる（Esc でも停止。確認ポイントの表示中はふじキュンが前面にあるので、そのまま Esc で止まります）

確認ポイントの表示中に、対象の画面をクリックしてカーソルを置いてから［続行］することもできます（テンプレートではこの方法で「最初の入力欄」を合わせています）。

流れ・変数・データ

LOOP_START（🔁 繰り返し）・BREAK・CONTINUE・IF_START（❓ もし〜なら）・ELSE・TRY_START（🧯 エラー時の処理）・SET_VAR（📦 変数に値を入れる）・STR_OP（✂ 文字を加工する）・ASK・RECORD・EXCEL_READ・EXCEL_WRITE は、16章 変数・繰り返し・分岐 で説明しています。

💡 ［追加］の行のボタンには日本語の名前（「キー送信」など）が表示されます。ボタンにマウスを乗せると、コマンド名（KEY など）と説明が出ます。

6. 差し込み

TEXT・RUN・SWITCH・WAIT_FOR・IF・CONFIRM・SCREENSHOT の値の中で {{ }} を使うと、実行時に値が入ります。編集ダイアログの［＋ 差し込みを追加 ▼］からも選べます。

書き方入る値例
{{1}} {{2}} …CSV の1列目、2列目…見本 太郎
{{氏名}}CSV の見出しが「氏名」の列見本 太郎
{{ROW}}CSV の行番号（データの1行目＝1）3
{{$合計}}変数「合計」の値（16章）1500
{{ROW+1}} {{ROW-2}}行番号に足し引きExcel のセル番地 A{{ROW+1}} → A4
{{COPY:伝票番号}}この行で COPY_SAVE した値R08-00123
{{TODAY}}今日2026/09/30
{{TODAY_JP}}今日2026年9月30日
{{WAREKI}}今日（和暦）令和8年9月30日
{{WAREKI_YEAR}}和暦の年令和8年
{{YYYYMMDD}}今日20260930
{{NOW}}時刻14:05
{{TIMESTAMP}}日時（ファイル名向け）20260930_140512
{{YEAR}} {{MONTH}} {{DAY}}年・月・日2026 9 30
  • 見出し名は 完全一致 です（前後の空白は無視）。分からない差し込みはそのまま残り、ログに警告が出ます。
  • CSV の見出しと同じ名前なら、見出しが優先 されます（例: 見出しが「DAY」の列があれば {{DAY}} はその列の値）。数字だけの見出しは {{列番号}} で指定してください（{{2026}} は「2026列目」と読まれます）。
  • 和暦は令和（2019年5月1日〜）・平成・昭和に対応しています。元年は「元年」と表示します。

7. キーの書き方（SendKeys）

KEY コマンドや、WAIT_FOR・IF の「押すキー」は、Windows の SendKeys の書き方です。

書き方キー書き方キー
{TAB}Tab+{TAB}Shift+Tab
{ENTER}Enter{ESC}Esc
{SPACE}スペース{BS}BackSpace
{DELETE}Delete{UP} {DOWN} {LEFT} {RIGHT}矢印
{HOME} {END}Home / End{PGUP} {PGDN}PageUp / PageDown
{F1}〜{F12}ファンクションキー{TAB 3}Tab を3回（回数指定）
^aCtrl+A^{HOME}Ctrl+Home
%{F4}Alt+F4%yAlt+Y（「はい(Y)」ボタンなど）
  • 記号の意味: ^ = Ctrl、+ = Shift、% = Alt
  • + ^ % ~ ( ) { } [ ] を文字として送るときは {+} のように { } で囲みます。
  • 文字を入力したいときは KEY ではなく TEXT を使ってください（日本語入力の影響を受けません）。

8. ウィンドウ名の合わせ方

対象ウィンドウ・SWITCH・WAIT_FOR・IF のタイトルは、ウィンドウのタイトルバーの文字を次の順で探します。

  1. 完全に一致するもの
  2. 先頭 が一致するもの
  3. 末尾 が一致するもの

例: Excel のタイトル「台帳.xlsx - Excel」は、台帳.xlsx（先頭）でも Excel（末尾）でも見つかります。途中の文字だけ（xlsx）では見つかりません。

［🔍 一覧］を押すと、いま開いているウィンドウのタイトル一覧から選べます（PowerShell を使います）。

対象ウィンドウ を設定すると、各行の最初にそのウィンドウを前面にします。空欄の場合は、実行開始から3秒待つので、その間に入力先をクリックするか、マクロの中で RUN・SWITCH してください。

9. 画面認識の3つの方法

ボタンを押す方法は3つあります。上から順に試すのがおすすめです。

方法強み弱み
CLICK オブジェクト認識画面の位置や大きさが変わっても動く。いちばん確実名前を持たない部品（独自描画のボタン、Citrix/RDP の中）には効かない
CLICK_POS 座標認識どんな画面でも使えるウィンドウの位置・大きさ・画面の拡大率が変わるとずれる
CLICK_IMG 画像認識Citrix/RDP の中など、中身が見えない画面でも使える色やテーマが変わると見つからない。数秒かかる

CLICK のコツ

  • ボタンに表示されている文字（「登録」「OK」など）を 完全一致 で指定します。
  • 対象ウィンドウ（または SWITCH したウィンドウ）とフォーカスのあるウィンドウの中を探します。

CLICK_POS のコツ

  • 編集画面の［📍 数秒後のマウス位置を取得］を押し、3秒以内に目的の場所へマウスを置くと座標が入ります。
  • 対象ウィンドウは 最大化 して使うとずれにくくなります。

CLICK_IMG のコツ

  • 編集画面の［📷 5秒後のマウス周辺を切り取り］を押し、5秒以内に対象の画面を前に出して、ボタンの真ん中にマウスを置きます。rpa_images フォルダに PNG が保存されます。
  • 切り取る範囲は ボタンの特徴的な部分だけ（文字＋枠の一部など）が見つかりやすいです。背景が大きく入ると失敗しやすくなります。
  • しきい値 0.9 は「90%以上のピクセルが一致したらクリック」の意味です。見つからないときは 0.85 などに下げます。低くしすぎると別の場所を押す恐れがあります。
  • 見つからないときは1秒おきに3回まで探し、それでもだめならアラームを鳴らして止まります。
  • 画像のパスが相対パス（例 rpa_images\img_….png）なら、HTA のフォルダを基準にします。フォルダごとコピーすれば別の PC でも使えます。

10. 実行

項目説明
▶ 実行選択中のマクロを、CSV の開始行〜終了行について実行します
開始行・終了行データ行の番号（見出しを除いて1から）。全角数字でもOK。数字以外が入っているときは実行しません（終了行は空欄なら最後まで）。試すときは両方1にして1件だけ
間隔ステップとステップの間の待ち時間（ミリ秒）。画面が追いつかないときは増やします
⏸ 一時停止次のステップの前で止まります。［▶ 再開］で対象ウィンドウに戻ってから続きを実行します
⏹ 停止すぐ止めます。ふじキュンの画面で Esc を押しても止まります。ロボットが入力中で別の画面が前にあるときは、Esc を約1秒長押し すると、どの画面からでも止まります
□ 毎ステップ前面化入力の前に毎回、対象ウィンドウを前面にします。途中で別の画面が割り込む環境で ON にします
□ 完了音全行が終わったら音で知らせます

実行中のブロックは黄色で表示されます。実行中はマクロを編集できません。

実行結果CSV

［↓ 実行結果CSV］を押すと gprime_result.csv を保存します。

  • 元のCSVの列 ＋ COPY_SAVE で記録した値 ＋ SCREENSHOT の保存先 ＋ 実行結果（完了／スキップ／エラー／中断）＋ 備考 ＋ 元データ行No ＋ 開始日時
  • Excel で開いて「実行結果」でフィルターすると、やり直しが必要な行がすぐ分かります。

エラー行CSV

［↓ エラー行をCSV保存］を押すと gprime_error_list.csv を保存します。元データと同じ列の並びなので、直してそのまま読み込めば、エラーになった行だけ再実行 できます。

  • エラー行CSV（と実行結果CSV）には「元データ行No」列があります。「1行目は見出し」を ON にしてこの列があるCSVを実行すると、{{ROW}} やログの行番号は 元のCSVの行番号 になるので、A{{ROW+1}} のようなセル番地もずれません。
  • IF の SKIP 以外のエラー（IF の STOP、タイムアウト、ウィンドウが見つからない、クリック失敗など）は 実行そのものが止まるので、その後ろの行はまだ処理されていません。エラー行を直したら、元のCSVで 開始行 をその次の行にして続きを実行してください。

11. 安全装置

しくみ内容
ウィンドウ見失い防止対象ウィンドウが見つからないときは1秒おきに最大3回探し、だめならアラーム＋停止
自分への誤入力防止入力先がふじキュン自身になりそうなときは、対象ウィンドウに戻すか、戻せなければ停止
アラーム異常停止・タイムアウト時に鳴ります。PowerShell → Windows Media Player 部品 → 音声合成 の順に、鳴らせる方法を自動で選びます。［🔔］でテストできます
確認ポイントCONFIRM で人の確認をはさめます。登録・送信などの前に入れるのがおすすめです
Esc で停止ふじキュンの画面で Esc を押すと止まります。ほかの画面が前にあるときは Esc を約1秒長押し（PowerShell が使える端末のみ。マクロの KEY {ESC} は一瞬なので反応しません）
自動保存編集のたびに一時ファイルへ保存。次回起動時に復元できます

13. マクロの共有（書出・取込）

  • ［📤 書出］: 選択中のマクロを macro_export\マクロ名.json に保存します。同じ名前のファイルがあるときは、上書きせずに マクロ名 (2).json のように番号を付けます。
  • ［📥 取込］: 書き出した JSON を選ぶと、マクロが追加されます（今あるマクロは消えません）。

CLICK_IMG の画像を使っているマクロを渡すときは、rpa_images フォルダも一緒に渡してください。

16. 変数・繰り返し・分岐

ほかの RPA ツールと同じように、変数・繰り返し（for / while）・もし〜なら（if / else）・エラー時の処理（try / catch） が使えます。プログラミングを知らなくても、ブロックを積み木のように並べて使えます。

変数

  • 変数は「名前の付いた箱」です。［📦 変数に値を入れる］・［✂ 文字を加工する］・［✍ 値を入力してもらう］・［📗 Excelのセルを読む］・［📋 値をコピーして記録］ で値が入ります。
  • 入れた値は、差し込みと同じ書き方の {{$名前}} でどこでも使えます（例: {{$合計}}）。
  • 変数の値は、1回の実行のあいだ 行をまたいで残ります。行ごとに最初から数えたいときは、マクロの最初で値を入れ直します。
  • まだ値が入っていない変数は、空っぽとして扱います。
  • 実行中の値は、下の ［🔎 変数］ パネルでリアルタイムに確認できます（変数・この行のCSVの値・コピーした値・繰り返しの回数）。

［📦 変数に値を入れる］の「計算して入れる」 では + - * / % とかっこが使えます。全角数字やカンマ付きの数（１，２００）もそのまま計算できます。例: {{単価}}*{{数量}}、{{$合計}}+{{金額}}

文字を加工する（✂）

元の文字（差し込み可）を加工して、結果を変数に入れます。

加工のしかた設定A設定B例
置換探す文字置きかえる文字a-b → A=- B=/ → a/b
正規表現で置換パターン置きかえる文字（$1 可）空白をそろえる A=[ 　]+ B=　
正規表現で取り出すパターンかっこの番号（空なら全体）電話番号 A=0\d{1,4}-\d{1,4}-\d{4}
切り出し何文字目から何文字（空なら最後まで）ABCDEFG A=3 B=2 → CD
区切って取り出す区切り文字（空ならカンマ）何番目山田,太郎 A=, B=2 → 太郎
前後の空白を消す全角の空白も消えます
全角→半角 / 半角→全角１２３ＡＢＣ ↔ 123ABC
ゼロ埋め桁数埋める文字（空なら0）123 A=7 → 0000123
日付を和暦に2026/10/01 → 令和8年10月1日
日付にA日を足す日数（マイナス可）2026/10/01 A=14 → 2026/10/15
3桁区切り / カンマを消す1234567 ↔ 1,234,567
文字数を数えるあいう → 3

日付は 2026/10/01・2026-10-1・20261001・令和8年10月1日・全角数字 のどれでも読めます。

条件（もし〜なら・条件のあいだの繰り返しで使う）

くらべ方意味
と等しい / と違う同じかどうか（両方が数なら数としてくらべます）
を含む / を含まない文字が入っているか
が空っぽ / が空っぽでない値が空か（くらべる相手は使いません）
より大きい / 以上 / より小さい / 以下数の大小（全角・カンマ付きもOK）
が正規表現に一致するくらべる相手に正規表現を書きます
というウィンドウがある / ない調べる値にウィンドウのタイトル（8章と同じ探し方）
というファイルがある / ない調べる値にファイルのパス

繰り返し（🔁）

  • 決めた回数くり返す（for）: 回数を数字か差し込み（{{ページ数}} など）で決めます。
  • 条件を満たすあいだくり返す（while）: 毎回、最初に条件を調べて、満たしているあいだ中身をくり返します。
  • 何回目かは {{$回数}}（変数名は変えられます）で使えます。入れ子の繰り返しでは、それぞれ別の名前にします。
  • ［⤴ 繰り返しを抜ける］（break） で途中で終わり、［↪ 次の繰り返しへ］（continue） で残りを飛ばして次の回に進みます。たいてい「もし〜なら」の中に入れて使います。
  • 終わらない繰り返しを防ぐため、上限回数（最初は1000回）を超えるとエラーで止まります。

もし〜なら（❓）

  • 条件が合うときだけ中身を実行します（if）。
  • ［↔ そうでなければ］（else） を中に1つ入れると、合わないときの手順を書けます。「もし〜なら」のブロック（またはその中の行）を選んでから追加します。
  • 「IF（ウィンドウ検知）」は 画面が出たら 動くコマンド、「もし〜なら」は 値で分ける コマンドです。

エラー時の処理（🧯）

  • 中でエラー（ウィンドウが見つからない・クリックできない・時間切れ など）が起きても止まらずに、［⚠ エラーのとき］（catch） から下を実行します（try / catch）。
  • エラーの内容は {{$エラー内容}} で使えます。実行結果CSVの備考にも「受け止めたエラー」として残ります。
  • IF（ウィンドウ検知）の STOP（緊急停止）と ⏹ 停止・Esc は受け止めません。本当に止めたい異常はちゃんと止まります。

そのほかの変数・データのコマンド

コマンド動き
ASK ✍ 値を入力してもらう実行中に入力欄を出して、入力された値を変数に入れます。「最初の1行だけ」グループに入れると、最初に1回だけ聞けます
RECORD 📝 結果に記録する値を実行結果CSVの列として残します
EXCEL_READ 📗 Excelのセルを読むExcelの画面を開かずに、ブックのセルの値を変数に入れます
EXCEL_WRITE 📗 Excelのセルに書くExcelの画面を開かずに、セルに書き込んで保存します。書き込むブックは閉じておいてください

Excel のコマンドは Excel が入っている PC で使えます（［🩺 環境チェック］で確認できます）。ブックは実行のあいだ裏で開いたままになり、実行が終わると閉じます。

ブロックのルール

  • 「繰り返し」「もし〜なら」「エラー時の処理」「グループ」は、どれも 始まりと終わりがセット のブロックです。追加するとセットで入り、▼/▶ で折りたためます。
  • 終わりの行だけを始まりより上に動かすなど、ブロックが壊れる操作はできません。壊れたマクロは実行しません。
  • ブロックの最初の行を無効化（⊘）すると、ブロックまるごと飛ばします。
