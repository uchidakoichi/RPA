# 準備

ふじキュン♡のおしごとロボットは、Windows に最初から入っている **Windows PowerShell 5.1** と Windows Forms だけで動きます。ほかのソフトのインストールは不要です。

## ファイルを置く

1. 書き込みできるフォルダ（例: `C:\RPA作業\`）を作ります。
2. GitHub のリポジトリの `dist` フォルダにある次の2つを、RAW 表示からメモ帳に貼り付け、このフォルダに同じ名前で保存します。自治体セキュリティクラウドのダウンロード機能では、ファイルが壊れることがあるのでダウンロードしないでください。
   - `fujikyun.b64.txt`（アプリ一式を文字にしたもの。約80万文字あります。Ctrl+A で全部選んでコピーします）
   - `fujikyun-restore.bat`（元に戻すためのバッチ）。保存の画面で「ファイルの種類」を「すべてのファイル」にします（「テキスト文書」のままだと末尾に `.txt` が付きます）。
3. `fujikyun-restore.bat` をダブルクリックします。同じフォルダに、アプリのファイル（`fujikyun.bat`・`fujikyun.ps1`・`fujikyun_ja.json`・`fujikyun_commands.json`・`fujikyun_templates.json`・説明書 `fujikyun_manual.html`・`LICENSE`）ができます。
   貼り付けが途中で切れていたり、2つの版が違ったりすると、何も書き換えずに「内容が一致しません」と出て止まります。そのときは2つとも貼り付け直します。
4. `fujikyun.bat` をダブルクリックします。
5. **［🩺 環境チェック］** で、この端末で使える機能を確認します。
6. **［📚 テンプレート］** からお手本マクロを作って、動かしてみましょう（[チュートリアル](tutorial.md)）。

マクロのファイル（`fujikyun_macros.json`）・見本CSV（`samples`）・参照画像（`rpa_images`）・証跡（`evidence`）・書き出したマクロ（`macro_export`）・予定（`fujikyun_settings.json`）は、このフォルダに作られます。別の PC に移るときは、フォルダごとコピーします。

新しい版に入れ替えるときも同じ手順です。2つを同じフォルダに上書き保存して `fujikyun-restore.bat` を実行すると、アプリのファイルだけがまとめて新しくなります。マクロ・設定・ログ・記録はそのまま残ります。ふじキュンを開いていたときは、一度閉じて開き直します。

アプリのファイルを1つずつ RAW 表示から貼り付けて置くこともできます（リポジトリ直下にあります）。そのときはファイル名をこのとおりにし、**JSON と HTML は文字コード「UTF-8」で保存** して、**まとめて** 置き換えます（`fujikyun.ps1` だけを新しくすると、起動時に「`fujikyun_ja.json` が古い」とお知らせが出ます）。

### 起動のしくみ

`fujikyun.bat` は、PowerShell 5.1 を STA モード（Windows Forms に必要）・コンソールなしで起動します。`-ExecutionPolicy Bypass` の指定はその1回の起動にだけ効き、端末の設定は変えません。グループポリシーで実行ポリシーが決められている端末では、ポリシーの方が優先されます。

### 安全のための動き

- 実行結果CSV・エラー行CSVで、ツールが付け足す列（記録した値・備考・エラー内容）が `=` などで始まるときは、Excel で数式として動かないよう先頭に `'` を付けます（元データの列はそのまま）。
- EXCEL_WRITE で、差し込みで入った値が `=` などで始まるときは文字として書きます。ステップに直接書いた数式（`=SUM(A1:A3)` など）は数式のままです。Excel のブックはマクロを無効にして開きます。
- 画像でクリックの参照画像がネットワーク上（`\\サーバー\…`）にあるときは、編集画面を開いただけでは読み込みません。

## 困ったとき

| こんなとき | どうする |
| --- | --- |
| ボタンなどが `gui.schedule` のような英字の名前で表示される | `fujikyun_ja.json` が古いままです。`fujikyun.ps1` と同じ版の `fujikyun_ja.json` に置き換えてください（起動時にもお知らせが出ます） |
| 起動すると「起動できなかったキュン」と出る | メッセージの内容を確認します。JSON を UTF-8 以外（Shift_JIS など）で保存すると読み込めません |
| 画面が出ない・すぐ消える | 5つのファイルが同じフォルダにあるか確認します。それでも出ないときは、PowerShell が組織の設定で止められていて、その端末では使えないことがあります |
| 起動に時間がかかる | ログの「⏱ 起動にかかった時間」の内訳を見ます |
| 予定が動かない | PC がスリープ・画面ロック中でないか、ログインしたままか、［⏰ 予定］で「✅ 有効」になっているかを確認します |

そのほかは [Q&A](faq.md) を見てください。

## 保守する人向け

ソースは `src`・`gui`・`build` フォルダにあり、`.ps1` は英数字（ASCII）だけで書いています。Windows PowerShell 5.1 は BOM のない `.ps1` を Shift_JIS として読むためで、日本語の文言はすべて UTF-8 の `fujikyun_ja.json` に分けています。

- `fujikyun.ps1` は `build/Build-FujiBundle.ps1` が `build/Main.ps1`・`src`・`gui` から作る1ファイルです（直接編集しない）。
- テスト：`tests/Invoke-FujiTest.ps1`（Windows では `tests\run_tests.bat`）。画面に依存しない部分（編集・実行の決まり・CSV・計算・和暦・予定・記録の変換・画像照合・OCR 結果の処理など）を、偽の画面操作で確かめます。
- 詳しくは [`DEVELOP.md`](https://github.com/uchidakoichi/RPA/blob/master/DEVELOP.md) を見てください。
