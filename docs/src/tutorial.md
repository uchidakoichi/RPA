# チュートリアル：はじめてのロボットづくり

RPA が初めての方向けに、レッスンを順に進めながら少しずつ使い方を覚えます。レッスン1〜4は **メモ帳と電卓だけ** で試せるので、職場のシステムに触らずに安心して練習できます。

| [0. 準備](#レッスン0準備) | 置き場所・起動・環境チェック | 5分 |
| [1. お手本を動かす](#レッスン1お手本を動かす) | テンプレートを実行して流れを見る | 10分 |
| [2. 自分で組み立てる](#レッスン2自分で組み立てる) | 空のマクロから作る・差し込みを使う | 20分 |

## レッスン0：準備

1. 書き込みできるフォルダ（例: `C:\RPA作業\`）を1つ作り、次の5つのファイルを置きます（[準備](setup.md#ファイルを置く)）。
   - `fujikyun.bat`・`fujikyun.ps1`・`fujikyun_ja.json`・`fujikyun_commands.json`・`fujikyun_templates.json`
2. `fujikyun.bat` をダブルクリックで起動します。
3. いちばん上の段の **［🩺 環境チェック］** を押します。
   - すべて **OK** なら準備完了です。
   - **NG** があっても大丈夫。どの機能が使えないかが表示されるので、[Q&A](faq.md) を参考にしてください。

> 💡 ふじキュンは、`fujikyun.bat` と同じフォルダにマクロや結果を保存します。専用のフォルダを1つ作って、その中で使うのがおすすめです。

**画面の見方**

| 場所 | あるもの |
| --- | --- |
| 上の3段 | 保存・予定・環境チェック ／ マクロの選択・テンプレート・対象ウィンドウ ／ CSV |
| 左側 | 「追加」のコマンド（分類ごとに1行）、実行の操作（▶ 実行・開始行・終了行・間隔 など）、ログ |
| 右側 | 「編集」の操作と、ブロック（マクロの手順）の一覧 |

左右の境目（薄い紫の線）はドラッグで動かせます。ブロックが多いときは左へ動かすと見やすくなります。

## レッスン1：お手本を動かす

**ゴール:** ロボットが「アプリを開く → 切り替える → 貼り付ける → キーを押す」様子を見る。

1. 上の段の **［📚 テンプレート］** を押します。
2. 「入門・Windows」の **「はじめての1本：メモ帳にCSVを入力」** の［✨ 作る］を押します。
   - マクロが追加され、見本CSV `samples\01_basic_meibo.csv` が自動で読み込まれます。
3. 表示されたブロックを上から読んでみましょう。

   | # | ブロック | 意味 |
   | --- | --- | --- |
   | 1 | 💬 COMMENT | 説明メモ（実行時は何もしない） |
   | 2〜5 | 📁 準備（最初の1行だけ） | 1行目のときだけメモ帳を起動して2秒待つ |
   | 6 | 🪟 SWITCH メモ帳 | メモ帳を前面にする |
   | 7〜14 | 📁 1行ぶんの入力 | CSV 1列目 → Tab → 2列目 → Tab → 3列目 → Enter |

4. 左側の **［▶ 実行］** を押し、手を離して見守ります。
5. メモ帳に5人分が入力されたら成功です 🎉

**やってみよう**
- 止め方を先に覚えておくと安心です。ロボットはメモ帳を前に出して入力するので、止めるときは **Esc を約1秒長押し** します（どの画面からでも止まります）。ふじキュンの画面をクリックしてから Esc か［⏹ 停止］でも止まります。
- 「間隔」を 300 → 1000 にすると、ゆっくり動くので流れが追いやすくなります。

## レッスン2：自分で組み立てる

**ゴール:** 空のマクロから作り、差し込み `{{ }}` を使う。

1. **［＋ 新規］** で「お知らせ文づくり」という名前のマクロを作ります。
2. CSV欄の［📂 参照］で `samples\02_letters.csv` を選びます（見出し: 氏名・イベント名・受付番号・会場）。
3. 「追加」の行から、次の順にコマンドを足します（追加したブロックが選ばれるので、次のブロックはその下に入ります）。

   1. **［🚀 アプリ起動］**（RUN）→ `notepad.exe`
   2. **［⏳ 待機］**（WAIT）→ `2000`
   3. **［🪟 ウィンドウ切替］**（SWITCH）→ `メモ帳`
   4. **［📝 文字列貼付］**（TEXT）→ 下の文章。［＋ 差し込みを追加 ▼］から `{{氏名}}` などを選んで入れられます。

      ```
      {{氏名}} 様
      受付番号は {{受付番号}} です。{{会場}} へお越しください。（{{WAREKI}}）
      ----
      ```

4. このままだと、**行ごとにメモ帳が開いてしまいます**。RUN と WAIT を「最初の1行だけ」にしましょう。
   1. RUN を選んだ状態で **［📁 グループ］** を追加し、名前を「準備」、実行タイミングを **「最初の1行だけ」** にします。
   2. RUN と WAIT のブロックを、ドラッグで「準備」グループの中（開始と終了の間）に入れます。
5. **開始行 1・終了行 1** にして［▶ 実行］。1通だけできることを確かめます。
6. 終了行を空欄（最後まで）にして、もう一度実行します。
7. **［💾 本番ファイルに保存］**（Ctrl+S）で保存します。

**ポイント**
- `{{列名}}` は CSV の見出しと **完全に同じ文字** にします。
- 入力は **TEXT（貼り付け）** が基本です。KEY は Tab や Enter などの「操作キー」に使います。

## レッスン3：操作を記録して作る

**ゴール:** ふだんの操作を1回だけ記録してたたき台にし、CSVの全行で動くマクロに仕上げる。

レッスン2では、コマンドを1つずつ選んで組み立てました。**［⏺ 記録］** を使うと、1件分の操作をやって見せるだけで、手順がブロックとして入ります。ここでは、メモ帳に名簿の1人分を手で入力して記録し、CSVの5人分を入力するマクロに仕上げます。

### 準備する

1. メモ帳を開いておきます（スタートメニューから「メモ帳」）。
2. **［＋ 新規］** で「記録で名簿入力」という名前のマクロを作ります。
3. CSV欄の［📂 参照］で `samples\01_basic_meibo.csv` を選びます（見出し: 氏名・フリガナ・電話番号）。

### 記録する

1. 編集の行の **［⏺ 記録］** を押します。ボタンが **［⏹ 記録終了（○件）］** に変わります（最初の1回だけ、準備に数秒かかります）。
2. メモ帳をクリックして前に出し、1人分を手で入力します。
   1. 日本語入力をオンにして `見本 太郎` と入力し、確定します。
   2. 日本語入力をオフにして、**Tab** を押します。
   3. `000-0000-0001` と入力して、**Enter** を押します。
3. ふじキュンの画面に戻って **［⏹ 記録終了］** を押します。「⏺ 記録した操作（日時）」グループとしてマクロに入ります。

記録されたブロックは、だいたい次のようになります（手の動かし方によって、クリックや待機の数は変わります）。

| ブロック | 意味 |
| --- | --- |
| 🪟 SWITCH メモ帳 | メモ帳が前に出た |
| 🎯 CLICK_POS（座標でクリック） | メモ帳の中をクリックした |
| 💬 コメント「ここで日本語を入力（変換）していたよ…」 | 日本語入力がオンのあいだの入力。**文字そのものは記録されません** |
| ⌨ KEY `{TAB}` | Tab を押した |
| 📝 TEXT `000-0000-0001` | 半角の文字を入力した |
| ⌨ KEY `{ENTER}` | Enter を押した |
| ⏳ WAIT | 操作の間が1.2秒以上あいた |

ここで実行すると、**毎回同じ人（記録したときの電話番号）** が入力されるだけです。ここからが仕上げです。

### 整えて仕上げる

1. **日本語のコメントを差し込みに置き換えます。**
   1. コメントのブロックを選んで、「追加」の行から **［📝 文字列貼付］**（TEXT）を足します（選んだブロックのすぐ後ろに入ります）。
   2. ［＋ 差し込みを追加 ▼］から `{{氏名}}` を選んで［OK］。
   3. コメントのブロックを選んで **Delete** で消します。
2. **記録した文字を差し込みに置き換えます。** TEXT `000-0000-0001` をダブルクリックし、中身を `{{電話番号}}` に変えます。
3. **座標クリックを消します。** CLICK_POS は、メモ帳の位置や大きさが変わるとずれます。SWITCH でメモ帳が前に出れば入力できるので、ここでは Delete で消します。
4. **余分な待機を消します。** 考えながら操作したときの WAIT は、要らなければ消します（ステップの間には、実行の操作の「間隔」の待ちが入ります）。
5. **グループに名前を付けます。** グループの始まりをダブルクリックし、名前を「1人分を入力」にします。
6. **メモ帳の起動を足します。** **［📁 グループ］** を追加して、名前を「準備」、実行タイミングを **「最初の1行だけ」** にし、ドラッグでいちばん上に動かします。その中に **［🚀 アプリ起動］**（RUN）`notepad.exe` と **［⏳ 待機］**（WAIT）`2000` を入れます（レッスン2の手順4と同じです）。
7. 開いていたメモ帳は閉じ（保存しない）、**開始行 1・終了行 1** にして［▶ 実行］。1人分が入ることを確かめます。
8. 終了行を空欄（最後まで）にして実行し、5人分が入ったら **［💾 本番ファイルに保存］**（Ctrl+S）で保存します。

**ポイント**
- 記録は **たたき台** です。「入力した文字 → 差し込み（`{{列名}}`）」「座標クリック → 消す、または CLICK_NAME・CLICK_TEXT・CLICK_IMG」に置き換えると、どの行でも同じように動く、安定したマクロになります。
- 日本語入力がオンのときの文字は記録されません。記録されたコメントの場所に TEXT か CSV を入れます。
- 名前のあるボタンを押すと CLICK_NAME、名前のある入力欄をクリックして文字を入れると **🧩 欄に入力（名前で）** として記録されます。職場のシステムでは、そのまま位置が変わっても動くブロックになることがあります。
- 記録されるものの一覧は [操作マニュアルの「画面操作の記録」](manual.md#画面操作の記録-記録) にあります。

## レッスン4：値を読み取る

**ゴール:** 画面の値をコピーして記録し、結果をCSVで受け取る。

1. **［📚 テンプレート］→「発見！便利ワザ」→「電卓で検算して結果を記録」** を作ります。
2. ［▶ 実行］すると、電卓で「単価×数量」を計算し、答えを **COPY「電卓の答え」** で変数に入れて記録します。
3. 終わったら **［↓ 実行結果CSV］** を押して、`fujikyun_result.csv` を Excel で開きます。
4. 「台帳の金額」と「電卓の答え」を見比べてください。**1件だけ合わない行** があるはずです。

**ここで覚えること**
- COPY で入れた値は、実行結果CSV の **列** になります。
- COPY は値を **変数** に入れるので、あとの TEXT で `{{$電卓の答え}}` と書けば、別の画面に貼り付けられます（例:「Excelの表を読みながら別の画面へ転記」テンプレート）。

## レッスン5：職場のシステムに向ける

**ゴール:** 本物の画面で、安全に1件だけ動かす。

ここからは職場のシステム（文書起案・財務会計・グループウェア・福祉システムなど）を使います。まずは **照会（見るだけ）** のテンプレートから始めましょう。

1. **［📚 テンプレート］** から、使うシステムに近いものを選びます。**［🔍 探す］** にシステム名ややりたいこと（例: `照会`、`撮影`）を入れると早く見つかります。
   - 初めてなら「文書番号で検索して決裁状況の画面を保存」「受給者の照会画面を連続で撮影」など **初級の照会系** がおすすめです。
2. **対象ウィンドウ** を合わせます。
   1. 使うシステムの画面を開いておきます。
   2. 対象ウィンドウの右の **［🔍 一覧］** を押し、システムのタイトルを選びます。
   3. タイトルに日付や件名など毎回変わる部分があれば、変わらない **先頭部分か末尾部分だけ** を残します（[マニュアル9章](manual.md#9-ウィンドウ名の合わせ方)）。
3. **ボタン名** を合わせます。CLICK_NAME「登録」などは、画面に表示されている文字と完全に同じにします。
4. **カーソルの位置** を合わせます。
   - テンプレートによっては、最初に **✋ 確認ポイント** で「入力欄をクリックしてから続行してね」と聞いてきます。画面の入力欄をクリックしてから［▶ 続行］を押します。
   - 慣れたら、無効になっている（薄い）CLICK_POS を開いて［📍 3秒後のマウス位置を取得］で座標を入れ、**⊘ 無効化** ボタンで有効にし、確認ポイントの方を無効化します。これで完全自動になります。
   - 入力欄に名前や見出しがある画面なら、もっと確実な方法があります。CLICK_POS と TAB の代わりに **🧩 欄に入力（名前で）** を追加し、編集画面の **［🎯 部品を指す］** で入力欄を指します。欄の名前が自動で入り、赤い枠で示されます。［🔍 見つかるか試す］で見つかることを確かめたら、座標もTABの回数も合わせる必要はありません。
5. CSV を自分のデータに差し替えます（見本CSVを Excel で開いて書き換え、CSV形式で保存）。
6. **開始行 1・終了行 1** で実行し、画面の動きを最後まで見守ります。
   - 最初は **［⏯ 1ステップずつ］**（F10）で実行すると安心です。毎ステップの前で止まるので、［⏭ 次へ］で1つずつ進めながら、画面の動きを確かめられます。気になるステップだけ止めたいときは、そのステップを選んで **［🔴 止める所］**（F9）を付けます。
   - 途中のステップを直したら、そのステップを選んで **［▶ ここから］**（F6）や **［▶ これだけ］** で、直した所だけを試せます。
7. 問題がなければ終了行を増やして、少しずつ件数を増やします。

> ⚠ 登録・送信・決裁など **取り消しにくい操作の前には、確認ポイント（CONFIRM）を入れておきましょう**。十分に試して安心できたら、確認ポイントを無効化して連続実行にします。

## レッスン6：止まらないロボットにする

**ゴール:** よくある「途中で止まる」を防ぐ。

| 症状 | 対策 |
| --- | --- |
| 画面が出る前に入力してしまう | WAIT を増やす。別ウィンドウが開くなら **WAIT_FOR**（出るまで待つ）に変える |
| ときどき「お知らせ」が出て止まる | **WINDOW_CHECK**（モード CONTINUE）で「出ていたら閉じて続行」 |
| 「該当なし」の行で止まる | **WINDOW_CHECK**（モード SKIP）で「その行は飛ばして記録」 |
| 想定外のエラー画面 | **WINDOW_CHECK**（モード STOP）で「アラームを鳴らして停止」 |
| 入力欄に前の文字が残る | 貼り付けの前に **KEY `^a`**（全選択）を入れる。**🧩 欄に入力（名前で）** なら中身を入れ替えるので要らない |
| ときどき失敗するが、やり直すとうまくいく | その部分を **🔂 うまくいくまでやり直す** で囲む（回数と待ち時間を決められる） |
| ログインのパスワードをマクロに書きたくない | **🔑 パスワードを入力** で、Windows の資格情報マネージャーに登録したものを打ち込む |

**エラーになった行だけやり直す**
1. 実行が終わったら **［↓ エラー行をCSV保存］** を押します（`fujikyun_error_list.csv`）。
2. Excel で開いて原因を直します（右端に「エラー内容」が付いています）。
3. そのCSVを読み込んで、もう一度実行します。「元データ行No」の番号がそのまま使われるので、`{{ROW}}` もずれません。
4. WINDOW_CHECK の SKIP 以外のエラー（STOP・タイムアウト・ウィンドウが見つからない など）は実行そのものが止まるので、その後ろの行がまだ残っています。元のCSVに戻して、**開始行** を続きの行にして実行します。

**証跡を残す**
- 登録のあとに **SCREENSHOT** を入れると、画面が `evidence\日付\` に保存されます。ファイル名に `{{ROW}}` や `{{氏名}}` を入れておくと、あとで探しやすくなります。
- エラーで止まったときは、その瞬間の画面が自動で `evidence\日付\エラー_行○_時刻.png` に保存されます。

## レッスン7：変数・繰り返し・分岐を使う

**ゴール:** 値を加工したり、条件で分けたり、エラーでも止めずに続けたりする。

1. **［📚 テンプレート］→「変数・繰り返し・分岐」** を開きます。メモ帳だけで試せるものが入っています。
2. **「全角・半角や桁数がバラバラな番号をそろえてから入力」** を作って実行し、実行の操作の **［📊 変数］** を押して、`$番号7桁` や `$電話` が行ごとに変わる様子を見てみましょう。
3. **「金額で分岐：10万円以上だけ人が確認してから入力」** を実行すると、高額の行だけ確認ポイントで止まります。❓もし〜なら と ↔そうでなければ の位置を見てください。
4. **「エラーが出ても止めずに記録して次の行へ」** を実行すると、2行目はわざとエラーになりますが、止まらずに3行目まで進みます。［↓ 実行結果CSV］の「結果」列を見てみましょう。

**ポイント**
- 変数は `{{$名前}}` で使います（CSVの列は `{{列名}}`、変数は `$` 付き）。
- 繰り返し・もし〜なら・エラー時の処理は、グループと同じく「始まり〜終わり」のブロックです。
- くわしくは [操作マニュアル 7章](manual.md#7-変数繰り返し分岐) を見てください。
