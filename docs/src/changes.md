# 更新履歴

使っている版は、タイトルバーの「（バージョン …）」か、**［🩺 環境チェック］** の「ふじキュンのバージョン」で確かめられます。数字はその版を出した日付（年.月.日）です。

新しい版にするときは、`fujikyun.ps1` と `fujikyun_ja.json` などの JSON を、いっしょに置き換えてください。マクロ（`fujikyun_macros.json`）と予定・設定（`fujikyun_settings.json`）はそのまま使えます。

---

## 2026.10.23.2

**変わったこと**
- 説明書を `fujikyun_manual.html` の1ファイルにしました。`fujikyun.ps1` と同じフォルダに置くと、［📖 説明書］と F1 で開けます（これまでの `docs` フォルダは使いません）。
- 見本CSV の zip を `dist/fujikyun_samples.zip` にしました（説明書は入っていません）。
- ［🩺 環境チェック］に **［📋 結果をコピー］** を付けました。問い合わせのときに、バージョンと結果をそのまま貼り付けられます。
- 説明書の目次にライセンスを、操作マニュアル16章に個人情報の扱いを書きました。

**直したこと**
- 予定と見た目の設定（`fujikyun_settings.json`）も、保存の途中で止まっても壊れないようにしました。
- Excel で開いたままの CSV を、ふじキュンで読み込めるようにしました（これまでは「ほかのプロセスが使用中」で読めませんでした）。
- 書き出す先のファイル（実行結果CSV など）を Excel などが開いていて書けないときに、「そのアプリで閉じてから、もう一度」と分かる言葉で知らせるようにしました。
- マクロの保存に失敗したときに、作業用の一時ファイル（`….saving`）が残らないようにしました。
- このPCの設定ファイル（`fujikyun_settings.json`）が壊れていたときに、黙って標準の設定で始めていたのを、起動時に知らせるようにしました。元のファイルは `fujikyun_settings_broken_日時.json` にコピーして残します。
- マクロファイルの形になっていない JSON を「マクロが0件のファイル」として読み、次の保存で上書きしてしまうことがあったのを直しました。読めないファイルと同じく、コピーを残して保存の前に確かめます。
- 思いがけないエラーが起きたときに、英語の「ハンドルされていない例外」の窓（押すとアプリが終わる［Quit］ボタン付き）が出ることがあったのを、ログに記録して続けるようにしました。
- CSV の場所の欄に Windows で使えない文字（`|` など）を入れたときに、「見つからない」と知らせるようにしました。
- `{{ROW+…}}` にとても大きな数を書いたときに、エラーにならずそのままの文字にしました。

## 2026.10.23

**新しくなったこと**
- エラーで止まったときに、画面全体を色で光らせて知らせるようにしました。まわりがうるさくてアラーム音に気づけないときも、離れた所から分かります。［確認しました］を押すまで消えず、止まってからの時間も出ます。
- 実行バーの［🚨 知らせ方］で、知らせ方を選べるようにしました。
  - 表示：画面全体／画面の縁だけ／表示しない
  - 色、ゆっくり点滅するかどうか
  - 音の種類（アラーム1〜10・着信音1〜10）と、確認されるまで音をくり返すかどうか（間隔は1〜30分）
- 確認ポイントや「値を入力してもらう」で人を待っているときも、エラーとは別の色・音で知らせられるようにしました（はじめは画面の縁を黄色で光らせ、音は鳴らしません）。
- 知らせを確認したら、いつから何分待っていたかをログに残すようにしました。

## 2026.10.22

はじめてバージョン番号を付けた版です。これより前の版には番号がありません。

**新しくなったこと**
- タイトルバーと［🩺 環境チェック］に、バージョンを出すようにしました。
- 同じフォルダのふじキュンを2つ開けないようにしました。2つ目を開こうとすると、お知らせが出ます。2つ開くと、片方の編集が消えることがあったためです。別のフォルダに置いたふじキュンは、同時に開けます。
- ログを `fujikyun_logs` フォルダにも保存するようにしました。1日1ファイルで、30日たったものは起動時に消えます（[操作マニュアル 16章](manual.md#16-保存されるファイル)）。
- この更新履歴を説明書に加えました。

**直したこと**
- 「画像でクリック」の追加画面などで、絵文字の入った説明文が途中で切れて表示されていました。
- 実行バーの［実行結果CSV］［エラー行CSV］のボタンに、件数ではなく「({0})」と出ることがありました。
- Windows のタスクスケジューラに登録した予定の時刻に、ふじキュンを開いていると、同じ予定が2回実行されることがありました。今は開いているほうだけが実行します。
