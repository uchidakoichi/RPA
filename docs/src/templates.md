# テンプレート解説

> このファイルは `node tools/build_templates.js` で HTA 内のテンプレートデータから自動生成しています。直接編集せず、HTA の `TEMPLATES` を直してから再生成してください。

ふじキュン♡のRPAマクロビルダーには **67 種類** のテンプレート（お手本マクロ）が入っています。画面上部の **［📚 テンプレート］** から選んで **［✨ 作る］** を押すと、マクロが追加され、見本CSVが `samples` フォルダに用意されて自動で読み込まれます。

- 見本CSVの人名・番号・URL・メールアドレスはすべて **架空** です。
- 画面のボタン名・ウィンドウ名・TAB の回数は職場のシステムごとに違います。各テンプレートの「準備」「カスタマイズのポイント」を読んで合わせてください。
- 基幹系システムや庶務事務システムのテンプレートは、メニュー名・ボタン名・欄の並びを **架空の例** で書いています（自治体ごとに画面が違うため）。最初は確認ポイント（✋）で入力欄を手でクリックする半自動で動き、慣れたら無効化されている座標クリック（CLICK_POS）や読み取りグループを有効化して完全自動にできます。
- はじめて動かすときは、実行欄の **開始行・終了行を両方 1** にして 1 件だけ試しましょう。

### はじめての1本：メモ帳にCSVを入力（初級）

メモ帳を自動で開いて、CSVの「氏名・フリガナ・電話番号」を1行ずつ入力します。RPAの基本「開く→切り替える→貼り付ける→キーを押す」が全部入っています。

- **こんな時に:** まず動きを見てみたいとき。ここで流れをつかめば、ほかのテンプレートも読めるようになります。
- **対象ウィンドウ:** なし（マクロの中で RUN・SWITCH して切り替えます）
- **見本CSV:** `samples/01_basic_meibo.csv`（列: `氏名`・`フリガナ`・`電話番号`）

**準備**

- 特になし（メモ帳は自動で開きます）

**ステップ**

| # | コマンド | 設定 | 補足 |
| --- | --- | --- | --- |
| 1 | `COMMENT` コメント | `はじめての1本！メモ帳を自動で開いて、CSVを1行ずつ入力するよ。▶実行を押して見ていてね` |  |
| 2 | `GROUP_START` グループ | `準備（最初の1行だけ）` | 最初の1行だけ |
| 3 | `RUN` アプリ起動 | `notepad.exe` |  |
| 4 | `WAIT` 待機 | `2000` |  |
| 5 | `GROUP_END` グループ終了 |  |  |
| 6 | `SWITCH` ウィンドウ切替 | `メモ帳` |  |
| 7 | `GROUP_START` グループ | `1行ぶんの入力` |  |
| 8 | `CSV` CSV列を貼付 | `1` |  |
| 9 | `KEY` キー送信 | `{TAB}` |  |
| 10 | `CSV` CSV列を貼付 | `2` |  |
| 11 | `KEY` キー送信 | `{TAB}` |  |
| 12 | `CSV` CSV列を貼付 | `3` |  |
| 13 | `KEY` キー送信 | `{ENTER}` |  |
| 14 | `GROUP_END` グループ終了 |  |  |

**カスタマイズのポイント**

- CSVの列を増やしたら、CSVブロックとTABブロックを追加します
- 区切りをカンマにしたいときは KEY {TAB} を TEXT「,」に変えます

**応用・発見のヒント**

- メモ帳の代わりに社内システムの入力画面に向ければ、そのまま入力ロボットになります

| 2 | `GROUP_START` グループ | `準備（最初の1行だけ）` | 最初の1行だけ |

### ページを順番に開いて画面を証跡保存（初級）

CSVに並べたURL（社内ポータルやシステムの照会ページ）を1つずつEdgeで開き、画面をPNGで保存します。

- **こんな時に:** 毎月の点検で「このページがこう表示されていた」という証跡（エビデンス）を残すとき。
- **対象ウィンドウ:** なし（マクロの中で RUN・SWITCH して切り替えます）
- **見本CSV:** `samples/03_urls.csv`（列: `ページ名`・`URL`）

**準備**

- Microsoft Edge が使えること
- CSVのURLを、自分の職場のページに書き換えること（見本のURLは架空です）

**ステップ**

| # | コマンド | 設定 | 補足 |
| --- | --- | --- | --- |
| 1 | `COMMENT` コメント | `見本のURLは架空だよ。CSVを自分の職場のページに書き換えてね` |  |
| 2 | `RUN` アプリ起動 | `msedge "{{URL}}"` |  |
| 3 | `WAIT` 待機 | `4000` |  |
| 4 | `SWITCH` ウィンドウ切替 | `Edge` |  |
| 5 | `SCREENSHOT` 画面を撮影して保存 | `画面を撮影「{{ページ名}}」（ウィンドウ）` |  |
| 6 | `KEY` キー送信 | `^w` |  |
| 7 | `WAIT` 待機 | `800` |  |

**カスタマイズのポイント**

- 読み込みが遅いページは WAIT を 4000→8000 などに増やします
- 画面全体を撮りたいときは SCREENSHOT の範囲を「画面全体」にします

**応用・発見のヒント**

- 保存先は ふじキュンのフォルダ\evidence\日付\ です。月ごとにフォルダを分けて保管すると監査対応がラクになります

| --- | --- |
| お知らせ一覧 | http://portal.example/info |
| 庁内掲示板 | http://portal.example/board |

### Excelの台帳に1行ずつ転記（初級）

開いているExcelの台帳に、CSVの内容を「A列の○行目」から順に転記します。ジャンプ（Ctrl+G）で書き込む行を毎回指定するので、途中で止めても行がずれません。

### 全角・半角や桁数がバラバラな番号をそろえてから入力（初級）

- **こんな時に:** 手入力のExcelや他課からもらったデータは、全角半角や桁数がそろっていないことがよくあります。システムに入れる前に整えると、検索で「該当なし」になりません。

**準備**
