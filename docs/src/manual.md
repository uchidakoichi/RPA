# ふじキュン♡のおしごとロボット 操作マニュアル

Windows だけで動く RPA（パソコン作業の自動化）ツールです。インストール不要で、`fujikyun.bat` をダブルクリックすると起動します。ネットワークにはつながりません。

- はじめての方は [チュートリアル](tutorial.md) から読むのがおすすめです。
- お手本マクロの解説は [テンプレート解説](templates.md) にあります。
- 困ったときは [Q&A](faq.md) を見てください。

## 1. 動作環境と置き場所

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11 |
| 必須 | Windows に最初から入っている **Windows PowerShell 5.1**（言語モードが FullLanguage であること）。ほかのソフトのインストールは不要です |
| Excel / Outlook | EXCEL_READ・EXCEL_WRITE は Excel、MAIL の Outlook 送信は Outlook が入っている PC で使えます |
| ファイル | `fujikyun.bat`・`fujikyun.ps1`・`fujikyun_ja.json`・`fujikyun_commands.json`・`fujikyun_templates.json` の5つを **同じフォルダ** に置きます（JSON は UTF-8 で保存。[準備](setup.md#ファイルを置く)） |
| 置き場所 | **書き込みできるフォルダ**に置いてください（例: `C:\RPA作業\` やドキュメント）。マクロやログはこのフォルダに保存されます |

起動したら、まず **［🩺 環境チェック］** を押して、その端末で使える機能を確かめましょう（[18章](#18-環境チェック)）。

- **左右の境目**（薄い紫の線）はドラッグで動かせます。ウィンドウの大きさを変えると、右のブロック一覧が伸び縮みします。
- **ウィンドウの位置・大きさ・左右の境目の位置** は、閉じるときにこの PC に覚えておき、次に開いたときに元に戻ります（最大化していたときも）。そのとき使っていたモニターを外したときは、画面の真ん中に開きます。
- **［🔠 文字の大きさ］** で、画面の文字とボタンの大きさを 90%〜200% から選べます。文字が小さくて読みにくいときに大きくします。次に起動したときから変わります（選んだときに「いま起動し直す」も選べます）。この PC だけの設定です。
- **［📖 説明書］** で、チュートリアル・操作マニュアル・テンプレート解説・Q&A をブラウザで開けます。**F1** を押すと、選んでいるステップのコマンドの説明が開きます。ステップの編集画面の［📖 このコマンドの説明］、テンプレート選択の［📖 解説を読む］、予定・環境チェック・パスワード登録の画面の［📖 説明］からも、その画面の説明へ直接飛べます。
  - 説明書は、`fujikyun_manual.html` を `fujikyun.ps1` と同じフォルダに置いておくと、ネットにつながっていなくても開けます（[準備](setup.md#ファイルを置く)）。見つからないときは、GitHub で読むかどうかを聞きます。

- **保存状態**: 「● 未保存の変更あり」のときは、編集内容が一時ファイルにだけ保存されています。［💾 本番ファイルに保存］（Ctrl+S）で確定します。
- **追加**: コマンドのボタンが7つの分類ごとに1行ずつ並んでいます（左側が狭いときは、分類の中で折り返します）。ボタンにマウスを乗せると、コマンド名（KEY など）と説明が出ます。
- **ブロック**: 1つのブロックが1つの命令（コマンド）です。左端とコマンド名の色で分類が分かります。

| 色 | 分類 | コマンド |
| --- | --- | --- |
| 青 | 入力 | KEY・TEXT・CSV・COPY |
| 黄土 | 待つ・確かめる | WAIT・WAIT_FOR・WINDOW_CHECK・CONFIRM |
| 緑青 | クリック・読み取り | CLICK_NAME・CLICK_TEXT・CLICK_IMG・CLICK_POS・READ_TEXT |
| 紫 | アプリ・画面 | SWITCH・RUN・SCREENSHOT・MAIL |
| 橙 | 流れ | LOOP_START・BREAK・CONTINUE・IF_START・ELSE・TRY_START・CALL_MACRO・RETURN |
| 藍 | 変数・データ | SET_VAR・STR_OP・ASK・RECORD・EXCEL_READ・EXCEL_WRITE・FILE_OP |
| 茶・緑 | 整理 | GROUP_START（グループ）・COMMENT（コメント） |

## 3. 基本の考え方：CSVの1行＝1回

ふじキュンは **マクロ（手順）を、CSVの行の数だけくり返します**。

```
CSV                        マクロ
氏名,電話番号               ① SWITCH 入力画面へ
見本 太郎,000-0000-0001  →  ② CSV 1列目を貼付
試験 花子,000-0000-0002  →  ③ KEY  Tab
練習 一郎,000-0000-0003  →  ④ CSV 2列目を貼付
                            ⑤ KEY  Enter
```

- 「1行目は見出し」にチェックがあると、1行目は見出しとして扱い、2行目からくり返します（初期値はチェックあり）。
- CSV を読み込まずに実行すると、マクロを **1回だけ** 実行します（CSV コマンドは空欄扱い）。
- 文字コードは自動判定（UTF-8 → だめなら Shift_JIS）です。Excel で「CSV（コンマ区切り）」で保存したファイルもそのまま読めます。
- `"` は Excel と同じく、値の **先頭** にあるときだけ囲み文字として扱います（`12"モニタ` のような値はそのまま文字として読みます）。`"` の閉じ忘れや、列の数がほかと違う行があると、読み込み時にログで知らせます。
- 途中の **空の行** は行番号を数えたまま残し、実行のときは飛ばします（`{{ROW}}` や Excel の行がずれません）。
- **Excel のブック（.xlsx・.xlsm・.xls）もそのまま読み込めます**。CSV の欄でブックを選ぶと、**1枚目のシート** を、セルに見えているとおり（日付や3桁区切りもそのまま）に読みます。CSV に保存し直す手間はいりません。読み込みには Excel が入っている PC が必要です。ブックは読み取り専用で開き、ブックのマクロは動かしません。

## 4. マクロの作成と編集

### 作り方は4通り

1. **［📚 テンプレート］から作る**（おすすめ）: お手本を選んで［✨ 作る］。見本CSVも自動で読み込まれます。
   - **［🔍 探す］** に「PDF」「コピー」「メール」のようなことばを入れると、名前・説明・使い道にそのことばを含むものだけが出ます。スペースで区切ると、全部を含むものにしぼれます（例: `Excel PDF`）。分類の横の数字は、その分類のテンプレートの数です。
2. **［＋ 新規］で空のマクロから作る**: 「追加」の行のボタンでコマンドを足していきます。
3. **［⏺ 記録］で操作を記録する**: ふだんの操作をコマンドに変換します（下の「画面操作の記録」）。
4. **［📥 取込］で同僚が書き出したマクロを取り込む**（[17章](#17-マクロの共有書出取込)）。

### ブロックの操作

| したいこと | 操作 |
| --- | --- |
| 選ぶ | 1回クリック（水色になります）。次に追加するコマンドは **選んだブロックの後ろ** に入ります |
| 編集する | ダブルクリック、［✎ 編集］、または Enter |
| 削除する | ［✕ 削除］、または Delete。グループ・繰り返しなどのブロックは「中身ごと削除」か「枠だけ解除」を選べます |
| 並べ替える | ドラッグ＆ドロップ（青い線の位置に入ります）、または ▲▼（Alt+↑↓） |
| 複製する | ⧉ 複製（Ctrl+D）。ブロックなら中身ごと複製します |
| 一時的に止める | ⊘ 無効化（Ctrl+/）。灰色で「無効」と表示され、実行時は飛ばされます。もう一度押すと元に戻ります |
| 元に戻す | ↩ 元に戻す（Ctrl+Z）／ ↪ やり直し（Ctrl+Y）。履歴▼から好きな時点にも戻れます（最大30件） |

### 始まりと終わりがあるブロック

「グループ」「繰り返し」「もし〜なら」「エラー時の処理」は、どれも **始まりと終わり（ここまで）がセット** のブロックです。

- 追加するとセットで入り、中のブロックは字下げされます。左の ▼/▶ で折りたためます。
- ブロックの最初の行を無効化（⊘）すると、**ブロックまるごと飛ばします**。
- 終わりの行だけを始まりより上に動かすなど、ブロックが壊れる操作はできません。形が壊れたマクロは実行しません。
- 「そうでなければ（ELSE）」は「もし〜なら」の中、「エラーのとき（CATCH）」は「エラー時の処理」の中に、それぞれ1つだけ置けます。

### グループの実行タイミング

グループには **実行タイミング** を設定できます。

- 毎行（ふつう）
- **最初の1行だけ**: アプリの起動、ログイン、画面を開く、ASK で値を聞くなどの「準備」に
- **最後の1行だけ**: 保存、閉じる、報告メールなどの「後片付け」に（最後の行がスキップされても実行します）

### 画面操作の記録（⏺ 記録）

1. 記録した操作を入れたい場所のすぐ上のブロックを選びます（何も選ばなければ最後に入ります）。
2. 編集の行の **［⏺ 記録］** を押します。ボタンが **［⏹ 記録終了（○件）］** に変わります。
3. ふだんどおりに操作します。ふじキュンの画面での操作は記録しません。
4. 終わったら **［⏹ 記録終了］** を押すと、「⏺ 記録した操作」グループとしてマクロに入ります。

| 操作 | 記録されるコマンド |
| --- | --- |
| ウィンドウの切り替え | SWITCH（タイトルの「 - 」より後ろ、例: `メモ帳` `Excel`） |
| 名前のあるボタンのクリック | CLICK_NAME（位置が変わっても動く） |
| 名前のある入力欄をクリックして文字を入力 | FIELD_SET（欄に入力（名前で）。位置が変わっても動く） |
| それ以外のクリック | CLICK_POS（座標。ダブルクリック・右クリックも区別） |
| Tab・Enter・矢印・F1〜F12・Ctrl+C など | KEY（同じキーの連続は `{TAB 3}` のようにまとめる） |
| 半角の文字入力 | TEXT |
| 日本語入力（IME がオン） | 「ここで日本語を入力していた」というコメント（TEXT か CSV に置き換えます） |
| 操作の間があいたとき（1.2秒以上） | WAIT |

記録はあくまで **たたき台** です。記録したあと、入力した文字を TEXT や CSV（差し込み）に置き換え、座標クリックを CLICK_NAME・CLICK_TEXT・CLICK_IMG に置き換えると、ずっと安定します。最初の記録だけ、準備（小さな C# のコンパイル）に数秒かかります。

### 部品を指して名前を入れる（🎯 部品を指す）

「欄に入力（名前で）」「欄の値を読む（名前で）」「表を読み取ってCSVに保存」「名前でクリック」の編集画面には、次の2つのボタンがあります。名前を調べて打ち込む必要はありません。

| ボタン | 動き |
| --- | --- |
| **［🎯 部品を指す（3秒）］** | 押してから3秒以内に、相手の画面の入力欄・ボタン・表の上にマウスを置きます。その部品の名前（名前がなければすぐ左の見出し、それもなければ ID）が入り、部品が **赤い枠** で光ります |
| **［🔍 見つかるか試す］** | いま入っている名前で、**実行のときと同じ探し方** をして、見つかった部品を赤い枠で示します。対象ウィンドウ（マクロの設定）の中を探します。見つからないときは名前・見出しを見直します |

赤い枠が別の部品を囲んだときは、名前を書き換えるか、「何番目か」を変えて、もう一度［🔍 見つかるか試す］で確かめます。

### 作りながら試す（止める所・1ステップずつ・ここから）

ほかの RPA ツールと同じように、作りかけのマクロを **少しずつ確かめながら** 作れます。

| したいこと | 操作 |
| --- | --- |
| ここで止めたい | ステップを選んで **［🔴 止める所］**（F9）。行の番号の左に **赤い点** が付き、実行するとそのステップの **前** で止まります。もう一度押すと外れます |
| 1つずつ進めたい | **［⏯ 1ステップずつ］**（F10）で実行すると、毎ステップの前で止まります。止まっているあいだに **［⏭ 次へ］**（F10）で次の1つを実行、**［▶ 再開］**（F5）で最後まで続けます |
| 途中から試したい | ステップを選んで **［▶ ここから］**（F6）。前のステップを飛ばして、選んだステップから実行します（CSV の2行目からは、ふつうに最初から） |
| 1つだけ試したい | ステップ（ブロックなら中身ごと）を選んで **［▶ これだけ］**。そのステップだけを、CSV の開始行の1行ぶん実行して止まります |

- 止まっているあいだは、ふじキュンの画面が前に出ます。**［📊 変数］** で変数や CSV の値を確かめられます。［⏭ 次へ］や［▶ 再開］を押すと、対象ウィンドウに戻って続きを実行します。
- 止める所は、マクロのファイルに一緒に保存されます。⏰ 予定（スケジュール）で動くときは止まりません。
- コメントやブロックの終わりの目印には止める所を付けられません（1ステップずつのときも飛ばして進みます）。

## 5. コマンド一覧

編集ダイアログでは項目ごとに入力できるので、値の書式を覚える必要はありません（ファイルでの形は [20章](#20-マクロファイルの形式)）。「差し込み可」の項目では `{{氏名}}` などが使えます（[6章](#6-差し込み)）。

### 入力

| コマンド | 設定 | 動き |
| --- | --- | --- |
| **KEY** ⌨ キー送信 | 送るキー（例 `{TAB}`） | キーボード操作を送ります。書き方は [8章](#8-キーの書き方sendkeys) |
| **TEXT** 📝 文字列貼付 | 文字列（差し込み可） | クリップボード経由で貼り付けます（Ctrl+V）。日本語入力がONでも化けません |
| **CSV** 📄 CSV列を貼付 | 列番号（1始まり） | いま処理中の行の、指定した列の値を貼り付けます。空欄なら何もしません |
| **COPY** 📋 コピーして変数へ | 変数名 | いま選ばれている文字を Ctrl+C でコピーして変数に入れます。あとで `{{$変数名}}` として使え、**実行結果CSV にも同じ名前の列** で残ります。コピーした文字がクリップボードに載るのを待ち（最大3秒）、載ったらすぐ読むので、前に WAIT はいりません。3秒たっても載らないときは空っぽになり、ログに ⚠ が出ます。待っているあいだに一時停止したときは、再開してからコピーし直します |
| **FIELD_SET** 🧩 欄に入力（名前で） | 欄の名前・見出し・ID、入れる文字（差し込み可）、何番目か、入れ方 | 入力欄を **名前で探して** 文字を入れます。座標やTABの回数を合わせなくてよく、画面の配置が変わっても動きます（[10章](#欄に入力欄の値を読む名前でのコツ)） |
| **SECRET** 🔑 パスワードを入力 | 登録名、入力するもの（パスワード／ユーザー名） | Windows の資格情報マネージャーに登録したパスワード（ユーザー名）を、いまの入力欄に打ち込みます。値はマクロ・CSV・ログ・実行結果に残りません（[パスワードの扱い](#パスワードの扱いsecret)） |

> 💡 TEXT・CSV は「貼り付け」なので、入力欄にもともと文字があると後ろに追加されます。上書きしたいときは直前に `KEY ^a`（全選択）を入れます。COPY の前にも `KEY ^a` を入れると確実です。

### 待つ・確かめる

| コマンド | 設定 | 動き |
| --- | --- | --- |
| **WAIT** ⏳ 待機 | ミリ秒（1000＝1秒） | 指定時間待ちます |
| **WAIT_FOR** 👀 ウィンドウ出現待ち | タイトル（差し込み可）・押すキー・タイムアウト秒 | 指定タイトルのウィンドウが出るまで1秒ごとに見張り、出たらキーを押して次へ。時間切れならアラームを鳴らして停止します |
| **WINDOW_CHECK** ⚠ ウィンドウ検知 | タイトル（差し込み可）・押すキー・モード | そのウィンドウが **いま** 出ているかを確認。出ていたらキーを押して、モードに従います。出ていなければ何もせず次へ |
| **CONFIRM** ✋ 確認ポイント | メッセージ（差し込み可） | ロボットを止めてメッセージを表示し、人の判断を待ちます |

WINDOW_CHECK のモード:

| モード | 動き | 使いどころ |
| --- | --- | --- |
| `STOP` | アラームを鳴らして緊急停止（「エラー時の処理」でも受け止めません） | 想定外のエラー |
| `SKIP` | この行を打ち切り、エラー行として記録して次の行へ | 「該当なし」など、飛ばせばよいもの |
| `CONTINUE` | キーを押してそのまま続行 | ときどき出るお知らせ・上書き確認などを閉じる |

CONFIRM のボタン:

- **▶ 続行**: 対象ウィンドウに戻って続きを実行
- **⏭ この行をスキップ**: この行を打ち切って次の行へ
- **⏹ 停止**: 実行をやめる（Esc でも停止。確認ポイントの表示中はふじキュンが前面にあるので、そのまま Esc で止まります）

確認ポイントの表示中に、対象の画面をクリックしてカーソルを置いてから［続行］することもできます（テンプレートではこの方法で「最初の入力欄」を合わせています）。

| **CLICK_IMG** 🖼 画像でクリック | 画像ファイル・しきい値 | 画面から画像と同じ模様を探してクリックします |

## 6. 差し込み

「差し込み可」の項目の中で `{{ }}` を使うと、実行時に値が入ります。編集ダイアログの［＋ 差し込みを追加 ▼］からも選べます。

| 書き方 | 入る値 | 例 |
| --- | --- | --- |
| `{{1}}` `{{2}}` … | CSV の1列目、2列目… | `見本 太郎` |
| `{{氏名}}` | CSV の見出しが「氏名」の列 | `見本 太郎` |
| `{{$合計}}` | 変数「合計」の値（COPY・SET_VAR などで入れた値。[7章](#7-変数繰り返し分岐)） | `1500` |
| `{{ROW}}` | CSV の行番号（データの1行目＝1） | `3` |
| `{{ROW+1}}` `{{ROW-2}}` | 行番号に足し引き | Excel のセル番地 `A{{ROW+1}}` → `A4` |
| `{{TODAY}}` | 今日 | `2026/09/30` |
| `{{TODAY_JP}}` | 今日 | `2026年9月30日` |
| `{{WAREKI}}` | 今日（和暦） | `令和8年9月30日` |
| `{{WAREKI_YEAR}}` | 和暦の年 | `令和8年` |
| `{{YYYYMMDD}}` | 今日 | `20260930` |
| `{{NOW}}` | 時刻 | `14:05` |
| `{{TIMESTAMP}}` | 日時（ファイル名向け） | `20260930_140512` |
| `{{YEAR}}` `{{MONTH}}` `{{DAY}}` | 年・月・日 | `2026` `9` `30` |

- 見出し名は **完全一致** です（前後の空白は無視）。分からない差し込みはそのまま残り、ログに警告が出ます。
- CSV の見出しと同じ名前なら、**見出しが優先** されます（例: 見出しが「DAY」の列があれば `{{DAY}}` はその列の値）。数字だけの見出しは `{{列番号}}` で指定してください（`{{2026}}` は「2026列目」と読まれます）。
- 差し込んだ値にカンマや `"` が入っていても、ほかの設定とまざることはありません。
- 和暦は明治・大正・昭和・平成・令和に対応しています（各元号の初日で切り替え。例: 1926年12月24日は大正15年、25日は昭和元年）。元年は「元年」と表示します。

## 7. 変数・繰り返し・分岐

ほかの RPA ツールと同じように、**変数**・**繰り返し（for / while）**・**もし〜なら（if / else）**・**エラー時の処理（try / catch）** が使えます。プログラミングを知らなくても、ブロックを積み木のように並べて使えます。

### 変数

- 変数は「名前の付いた箱」です。**SET_VAR**・**STR_OP**・**ASK**・**EXCEL_READ**・**COPY**・**READ_TEXT**・**FILE_OP** などで値が入り、繰り返しの回数も変数に入ります。
- 入れた値は、差し込みと同じ書き方の **`{{$名前}}`** でどこでも使えます（例: `{{$合計}}`）。
- 変数の値は、1回の実行のあいだ **行をまたいで残ります**。行ごとに最初から数えたいときは、マクロの最初で値を入れ直します。
- まだ値が入っていない変数は、空っぽとして扱います。
- 実行中の値は、実行の操作の **［📊 変数］** パネルでリアルタイムに確認できます（変数・繰り返しの回数・この行のCSVの値）。

**SET_VAR の「計算して入れる」** では `+ - * / %` とかっこが使えます。全角数字やカンマ付きの数（`１，２００`）もそのまま計算できます。例: `{{単価}}*{{数量}}`、`{{$合計}}+{{金額}}`

> 💡 正確に計算できるのは **15けたまで** です。それより大きい数は、まちがった答えを出さないように計算をエラーにします。小数は10けたまでで四捨五入します。

### 文字を加工する（STR_OP）

元の文字（差し込み可）を加工して、結果を変数に入れます。

| 加工のしかた | 設定A | 設定B | 例 |
| --- | --- | --- | --- |
| 置換 | 探す文字 | 置きかえる文字 | `a-b` → A=`-` B=`/` → `a/b` |
| 正規表現で置換 | パターン | 置きかえる文字（`$1` 可） | 空白をそろえる A=`[ 　]+` B=`　` |
| 正規表現で取り出す | パターン | かっこの番号（空なら全体） | 電話番号 A=`0\d{1,4}-\d{1,4}-\d{4}` |
| 切り出し | 何文字目から | 何文字（空なら最後まで） | `ABCDEFG` A=3 B=2 → `CD` |
| 区切って取り出す | 区切り文字（空ならカンマ） | 何番目 | `山田,太郎` A=`,` B=2 → `太郎` |
| 前後の空白を消す | | | 全角の空白も消えます |
| 全角→半角 / 半角→全角 | | | `１２３ＡＢＣ` ↔ `123ABC` |
| ゼロ埋め | 桁数 | 埋める文字（空なら0） | `123` A=7 → `0000123` |
| 日付を和暦に | | | `2026/10/01` → `令和8年10月1日` |
| 日付にA日を足す | 日数（マイナス可） | | `2026/10/01` A=14 → `2026/10/15` |
| 3桁区切り / カンマを消す | | | `1234567` ↔ `1,234,567` |
| 文字数を数える | | | `あいう` → `3` |

日付は `2026/10/01`・`2026-10-1`・`20261001`・`令和8年10月1日`（明治〜令和）・全角数字 のどれでも読めます。存在しない日付（2月30日など）はエラーになります。

### 条件（もし〜なら・条件のあいだの繰り返しで使う）

| くらべ方 | 意味 |
| --- | --- |
| と等しい / と違う | 同じかどうか（両方が数なら数としてくらべます。16けた以上の番号は文字としてくらべます） |
| を含む / を含まない | 文字が入っているか |
| が空っぽ / が空っぽでない | 値が空か（くらべる相手は使いません） |
| より大きい / 以上 / より小さい / 以下 | 数の大小（全角・カンマ付きもOK） |
| が正規表現に一致する | くらべる相手に正規表現を書きます |
| というウィンドウがある / ない | 調べる値にウィンドウのタイトル（[9章](#9-ウィンドウ名の合わせ方)と同じ探し方） |
| というファイルがある / ない | 調べる値にファイルのパス |

### 繰り返し（LOOP_START）

- **決めた回数くり返す（for）**: 回数を数字か差し込み（`{{ページ数}}` など）で決めます。
- **条件を満たすあいだくり返す（while）**: 毎回、最初に条件を調べて、満たしているあいだ中身をくり返します。
- 何回目かは `{{$回数}}`（変数名は変えられます）で使えます。入れ子の繰り返しでは、それぞれ別の名前にします。
- **BREAK（繰り返しを抜ける）** で途中で終わり、**CONTINUE（次の繰り返しへ）** で残りを飛ばして次の回に進みます。たいてい「もし〜なら」の中に入れて使います。
- 終わらない繰り返しを防ぐため、**上限回数**（最初は1000回）を超えるとエラーで止まります。

### もし〜なら（IF_START）

- 条件が合うときだけ中身を実行します（if）。
- **ELSE（そうでなければ）** を中に1つ入れると、合わないときの手順を書けます。「もし〜なら」のブロック（またはその中の行）を選んでから追加します。
- **WINDOW_CHECK** は「画面が出たら」動くコマンド、**もし〜なら** は「値で分ける」コマンドです。もし〜なら の条件「というウィンドウがある」を使うと、画面が出たときの手順を何行でも書けます。

### エラー時の処理（TRY_START）

- 中でエラー（ウィンドウが見つからない・クリックできない・時間切れ など）が起きても止まらずに、**CATCH（エラーのとき）** から下を実行します（try / catch）。
- エラーの内容は `{{$エラー内容}}` で使えます。実行結果CSVの備考にも「受け止めたエラー」として残ります。
- **WINDOW_CHECK の STOP**（緊急停止）と **⏹ 停止・Esc** は受け止めません。本当に止めたい異常はちゃんと止まります。

### うまくいくまでやり直す（RETRY_START）

- 中でエラーが起きると、**決めた時間待ってから、中身を最初からやり直します**（UiPath の Retry Scope と同じ考え方です）。
- やり直す回数（最初の1回は数えません）と、やり直す前に待つ時間を決めます。何回目のやり直しかは `{{$やり直し回数}}` で使えます。
- 決めた回数やり直してもだめなら、いつものエラーとして止まります。外側に「エラー時の処理」があれば、そちらの「エラーのとき」へ進みます。
- 画面の反応が遅いシステムで、ときどき失敗する所（検索して結果を読む など）を囲むのに向いています。WINDOW_CHECK の STOP（緊急停止）と ⏹ 停止はやり直しません。

### ASK・RECORD・Excel

- **ASK** は「最初の1行だけ」グループに入れると、実行のはじめに1回だけ聞けます。
- **RECORD** の値と COPY の値は、実行結果CSVの列になります。
- Excel のコマンドは Excel が入っている PC で使えます（［🩺 環境チェック］で確認できます）。ブックは実行のあいだ裏で開いたままになり、実行が終わると閉じます。シートは名前か番号（1＝1枚目）、セル番地には `B{{ROW+1}}` のような差し込みが使えます。

### ファイルのコピー・移動・名前の変更（FILE_OP）

ダウンロードした帳票を決まったフォルダに移す、処理の済んだファイルの名前に「済_」を付ける、といった作業に使います。

| すること | 元のファイル | 行き先 |
| --- | --- | --- |
| コピーする | ファイルのパス（例 `C:\RPA作業\受付_{{1}}.pdf`） | フォルダ（最後に `\` を付ける。例 `C:\RPA作業\控え\`）か、新しいファイルのパス |
| 移動する | 同上 | 同上 |
| 名前を変える | 同上 | 新しい名前だけ（例 `済_{{1}}.pdf`）。同じフォルダの中で名前を変えます |

- 元のファイル名に `*`（何文字でも）や `?`（1文字）を使うと、合うファイルを **まとめて** コピー・移動できます（例 `C:\RPA作業\受信\*.pdf`）。このとき行き先はフォルダです。名前を変えるときは使えません。
- 行き先のフォルダが無ければ作ります。
- 行き先に同じ名前のファイルがあるときは、はじめはエラーにします（上書きしません）。「上書きする」を選ぶと置き換えます。
- まとめて操作するときは、先にすべての行き先を確かめてから始めます。1つでも問題があれば、どのファイルも動かしません。
- 「行き先のパスを入れる変数名」を決めると、行き先のパスがその変数に入ります。まとめて操作したときは `;` で区切って入るので、そのまま MAIL の添付に使えます。
- `C:\` などから始まらないパスは、ふじキュンのフォルダの中として扱います。パスに `..`（上のフォルダ）は使えません。
- ふじキュン自身のファイル（ふじキュンのフォルダにある `fujikyun` で始まるファイル）は操作しません。
- ほかのアプリで開いているファイルは、移動・名前の変更ができないことがあります。そのアプリで閉じてから実行してください。

## 8. キーの書き方（SendKeys）

KEY コマンドや、WAIT_FOR・WINDOW_CHECK の「押すキー」は、Windows の SendKeys の書き方です。

| 書き方 | キー | 書き方 | キー |
| --- | --- | --- | --- |
| `{TAB}` | Tab | `+{TAB}` | Shift+Tab |
| `{ENTER}` | Enter | `{ESC}` | Esc |
| `{SPACE}` | スペース | `{BS}` | BackSpace |
| `{DELETE}` | Delete | `{UP}` `{DOWN}` `{LEFT}` `{RIGHT}` | 矢印 |
| `{HOME}` `{END}` | Home / End | `{PGUP}` `{PGDN}` | PageUp / PageDown |
| `{F1}`〜`{F12}` | ファンクションキー | `{TAB 3}` | Tab を3回（回数指定） |
| `^a` | Ctrl+A | `^{HOME}` | Ctrl+Home |
| `%{F4}` | Alt+F4 | `%y` | Alt+Y（「はい(Y)」ボタンなど） |

- 記号の意味: `^` = Ctrl、`+` = Shift、`%` = Alt
- `+` `^` `%` `~` `(` `)` `{` `}` `[` `]` を文字として送るときは `{+}` のように `{ }` で囲みます。
- 文字を入力したいときは KEY ではなく **TEXT** を使ってください（日本語入力の影響を受けません）。

## 9. ウィンドウ名の合わせ方

対象ウィンドウ・SWITCH・WAIT_FOR・WINDOW_CHECK・条件「というウィンドウがある」のタイトルは、ウィンドウのタイトルバーの文字を次の順で探します。

1. 完全に一致するもの
2. **先頭** が一致するもの
3. **末尾** が一致するもの

例: Excel のタイトル「台帳.xlsx - Excel」は、`台帳.xlsx`（先頭）でも `Excel`（末尾）でも見つかります。途中の文字だけ（`xlsx`）では見つかりません。

［🔍 一覧］を押すと、いま開いているウィンドウのタイトル一覧から選べます。

**対象ウィンドウ** を設定すると、各行の最初にそのウィンドウを前面にします。空欄の場合は、実行開始から3秒待つので、その間に入力先をクリックするか、マクロの中で RUN・SWITCH してください。

## 10. クリックと読み取り（画面認識の4つの方法）

**入力欄に文字を入れる・欄の値を読むときは、まず「欄に入力（名前で）」「欄の値を読む（名前で）」を試してください**（下の「欄に入力・欄の値を読む（名前で）のコツ」）。クリックしてから TAB で移動する方法より、ずっと確実です。

ボタンを押す方法は4つあります。上から順に試すのがおすすめです。

| 方法 | 強み | 弱み |
| --- | --- | --- |
| **CLICK_NAME** 名前で | 画面の位置や大きさが変わっても動く。いちばん確実 | 名前を持たない部品（独自描画のボタン、Citrix/RDP の中）には効かない |
| **CLICK_TEXT** 文字で（OCR） | ボタンに文字が見えていれば押せる。位置が変わっても大丈夫 | 文字認識のぶん数秒かかる。似た文字を読み違えることがある |
| **CLICK_IMG** 画像で | Citrix/RDP の中など、中身が見えない画面でも使える | 色やテーマが変わると見つからない。数秒かかる |
| **CLICK_POS** 座標で | どんな画面でも使える | ウィンドウの位置・大きさ・画面の拡大率が変わるとずれる |

### CLICK_NAME のコツ
- ボタンに表示されている文字（「登録」「OK」など）を **完全一致** で指定します。
- 対象ウィンドウ（または SWITCH したウィンドウ）とフォーカスのあるウィンドウの中を探します。

### 欄に入力・欄の値を読む（名前で）のコツ

- 欄は次の順に探します。**① 欄そのものの名前か ID が同じもの → ② 見出し（「宛名番号：」のような文字）がその名前で、そのすぐ右（なければすぐ下）にある欄**。見出しの後ろの「：」「*」や前後の空白は無視します。
- 探す場所は、いまフォーカスのあるウィンドウと、対象ウィンドウ（または SWITCH したウィンドウ）です。
- 同じ名前の欄がいくつもあるときは「何番目か」で選びます（画面の並びの順）。
- 入れ方は「おまかせ」がおすすめです。欄に直接値を入れ、入れられない欄はその欄を選んで貼り付けます。Web の画面などで、直接入れても画面に反映されないときは「欄を選んで貼り付ける」にします。
- 欄が見つからないときはエラーで止まります。［🎯 部品を指す］と［🔍 見つかるか試す］（[4章](#部品を指して名前を入れる-部品を指す)）で名前を確かめてください。Citrix・リモートデスクトップの中や、独自に描いている画面の欄は、名前で探せないことがあります。そのときは CLICK_TEXT や CLICK_POS で欄を選んでから TEXT で入力します。

### 表を読み取る（TABLE_READ）のコツ

- 画面の一覧表（表・グリッド・リスト）を、見出しの行と一緒に CSV に保存します。表の名前を空にすると、いちばん大きい表を読みます。
- 保存先のパスが相対パス（例 `一覧_{{YYYYMMDD}}.csv`）なら、ふじキュンのフォルダに保存します。保存した CSV は、そのまま別のマクロのデータとして読み込めます。
- 保存するファイルは **.csv だけ** です。保存先に差し込んだ値（CSV の値や画面の文字）に `..`・`:`・先頭の `\`・改行が入っていると、ほかの場所のファイルを上書きしないように、保存せずに止まります（`2026\一覧` のようなフォルダ分けは使えます）。
- 画面に表示されている行だけを読む表もあります（長い一覧は、スクロールしないと中身ができない作りのものがあります）。全件そろっているか、行数（変数）と画面の件数を見比べてください。最大5000行まで読みます。
- `=` などで始まるセルは、Excel で開いたときに式として動かないように、先頭に `'` を付けて保存します。

### CLICK_TEXT・READ_TEXT のコツ（文字認識）
- Windows に入っている文字認識（OCR）を使います。外部ソフトやネット接続は不要です。日本語を読むには、Windows に日本語の文字認識が入っている必要があります（［🩺 環境チェック］で確認できます）。
- 範囲は「前面のウィンドウ」「画面全体」「範囲を指定」から選べます。［📍 範囲を取得］で左上と右下にマウスを置くと範囲が入ります。範囲を小さくするほど正確で速くなります。
- CLICK_TEXT は、同じ文字が複数あるときは「何番目（上から）」で選びます。見つからないときは1秒おきに3回まで探します。探す文字は2文字以上がおすすめです。
- 小さい文字は自動で拡大してから読み取ります。読み取りは完璧ではありません（`0` と `O`、`1` と `l` など）。大事な値は確認ポイントで確かめてください。
- READ_TEXT で読んだ全文から値だけを取り出すには、STR_OP の「正規表現で取り出す」を使います。

### CLICK_IMG のコツ
- 編集画面の［📷 5秒後のマウス周辺を切り取り］を押し、5秒以内に対象の画面を前に出して、ボタンの真ん中にマウスを置きます。`rpa_images` フォルダに PNG が保存されます。
- 最初の画像クリックだけ、準備（小さな C# のコンパイル）に数秒かかります。
- 切り取る範囲は **ボタンの特徴的な部分だけ**（文字＋枠の一部など）が見つかりやすいです。背景が大きく入ると失敗しやすくなります。
- しきい値 0.9 は「90%以上のピクセルが一致したらクリック」の意味です。見つからないときは 0.85 などに下げます。低くしすぎると別の場所を押す恐れがあります。
- 見つからないときは1秒おきに3回まで探し、それでもだめならアラームを鳴らして止まります。
- 画像のパスが相対パス（例 `rpa_images\img_….png`）なら、ふじキュンのフォルダ（`fujikyun.bat` のあるフォルダ）を基準にします。フォルダごとコピーすれば別の PC でも使えます。

### CLICK_POS のコツ
- 編集画面の［📍 3秒後のマウス位置を取得］を押し、3秒以内に目的の場所へマウスを置くと座標が入ります。
- 対象ウィンドウは **最大化** して使うとずれにくくなります。

## 12. マクロの呼び出し（部品化）

- **CALL_MACRO**（📞 マクロを呼び出す）で、ほかのマクロを部品（サブルーチン）として実行し、終わったら次の行に戻ってきます。
- ログイン・画面を開く・保存して閉じる など、いくつものマクロで使う手順を1つの「部品マクロ」にしておくと、直すときも1か所で済みます。
- 変数（`{{$名前}}`）と CSV の行は共通なので、値の受け渡しは変数でします。
- 部品マクロの途中で **RETURN**（↩ 呼び出し元に戻る）を使うと、そこで戻ります。いちばん外側のマクロで使うと、その行の残りを飛ばして次の行に進みます。
- 部品マクロの中でエラーが起きたとき、部品の中に「エラー時の処理」がなければ、呼び出した側の「エラー時の処理」が受け止めます。
- 呼び出しは10段まで（自分自身を呼び続ける間違いを防ぐため）。呼び出し先はマクロの名前を変えても切れません。

## 13. 実行

| 項目 | 説明 |
| --- | --- |
| ▶ 実行 | 選択中のマクロを、CSV の開始行〜終了行について実行します |
| 開始行・終了行 | データ行の番号（見出しを除いて1から）。全角数字でもOK。数字以外が入っているときは実行しません（終了行は空欄なら最後まで）。**試すときは両方1にして1件だけ** |
| 間隔 | ステップとステップの間の待ち時間（ミリ秒）。画面が追いつかないときは増やします |
| ⏸ 一時停止 | 次のステップの前で止まります。［▶ 再開］で対象ウィンドウに戻ってから続きを実行します |
| ⏹ 停止 | すぐ止めます。ふじキュンの画面で **Esc** を押しても止まります。ロボットが入力中で別の画面が前にあるときは、**Esc を約1秒長押し** すると、どの画面からでも止まります。名前・文字・画像でのクリックは別の処理で探すので、探している最中でも止められます |
| □ アラーム ／ 🔔 | 異常停止したときにアラームを鳴らします。🔔 でテスト再生できます |
| 🚨 知らせ方 | エラーで止まったときと確認を待っているときに、画面全体や画面の縁を色で光らせて知らせます（[下の説明](#知らせ方エラーと確認待ちを画面で知らせる)） |
| □ 毎ステップ前面化 | 入力の前に毎回、対象ウィンドウを前面にします。途中で別の画面が割り込む環境で ON にします |
| □ 完了音 | 全行が終わったら音で知らせます |
| 📊 変数 | 実行中の変数・繰り返しの回数・この行のCSVの値を、ログの右に表示します（もう一度押すと隠れます） |
| ⏱ 時間 | いちばん新しい実行で、ステップごとにかかった時間を一覧にします（[下の説明](#かかった時間-時間)） |

実行中のブロックは黄色で表示されます。実行中はマクロを編集できず、ふじキュンを閉じることもできません（⏹ 停止してから閉じます）。

### 実行結果CSV
［↓ 実行結果CSV］を押すと `fujikyun_result.csv` を保存します。
- 元のCSVの列 ＋ COPY・RECORD で記録した値 ＋ SCREENSHOT の保存先 ＋ **実行結果**（完了／スキップ／エラー／中断）＋ 備考 ＋ 元データ行No ＋ 開始日時
- Excel で開いて「実行結果」でフィルターすると、やり直しが必要な行がすぐ分かります。

### エラー行CSV
［↓ エラー行をCSV保存］を押すと `fujikyun_error_list.csv` を保存します。元データと同じ列の並びなので、**直してそのまま読み込めば、エラーになった行だけ再実行** できます。

- エラー行CSV（と実行結果CSV）には「元データ行No」列があります。「1行目は見出し」を ON にしてこの列があるCSVを実行すると、`{{ROW}}` やログの行番号は **元のCSVの行番号** になるので、`A{{ROW+1}}` のようなセル番地もずれません。
- WINDOW_CHECK の SKIP 以外のエラー（WINDOW_CHECK の STOP、タイムアウト、ウィンドウが見つからない、クリック失敗など）は **実行そのものが止まる**ので、その後ろの行はまだ処理されていません（「エラー時の処理」の中で起きたものを除く）。エラー行を直したら、元のCSVで **開始行** をその次の行にして続きを実行してください。

### かかった時間（⏱ 時間）

実行が終わったあとで［⏱ 時間］を押すと、いちばん新しい実行で **ステップごとにかかった時間** を一覧にします。時間のかかっている順に並ぶので、遅いステップ（待ち時間が長すぎる・画面の反応を待っている など）を探すのに使えます。

| 列 | 内容 |
| --- | --- |
| マクロ・No | どのマクロの何番目のステップか（呼び出した部品マクロのステップは、そのマクロの名前で出ます） |
| 回数 | そのステップを実行した回数（CSV の行の数 × 繰り返しの回数） |
| 合計・平均・最長 | かかった時間（秒）。そのステップの後の待ち（間隔）も入ります |
| 割合 | 実行全体の中で、そのステップが占めた割合 |

- 行をダブルクリックすると、そのステップを選びます。
- ［📋 表をコピー］で、Excel に貼り付けられる形でコピーできます。
- 確認ポイント・値の入力・止める所で人を待っていた時間も、そのステップの時間に入ります（止める所で止まっていた時間は入りません）。

### エラーで止まったときの画面

実行がエラーで止まると、**その瞬間の画面全体を自動で保存** します（`evidence\日付\エラー_行○_時刻.png`）。保存先はログに出て、実行結果CSVの「エラー時の画面」の列にも残ります。止まった原因を、あとから画面で確かめられます。

### 知らせ方（エラーと確認待ちを画面で知らせる）

まわりがうるさくてアラーム音に気づけない職場でも、通りがかった人が離れた所から気づけるように、画面を色で光らせて知らせます。実行バーの **［🚨 知らせ方］** で、「エラーで止まったとき」と「確認を待っているとき（確認ポイント・値を入力してもらう）」を別々に決められます。

| 設定 | 内容 |
| --- | --- |
| 表示 | **画面全体**: 画面全体を色で覆い、大きな文字で「エラーで止まっています」・マクロ名・内容・止まってからの時間を出します。［確認しました］か Esc で消えます。<br>**画面の縁だけ**: 画面の上に帯、まわりに枠を出します。画面の中は見えて操作もできます。上の帯を押すと消えます。<br>**表示しない**: 音だけで知らせます |
| 色 | ［色を変える…］で選びます。文字は、色に合わせて黒か白になります |
| ゆっくり点滅する | 1秒ごとに、選んだ色と少し暗い色を入れかえます（速い点滅はしません） |
| 音 | アラーム1〜10・着信音1〜10（Windows に入っている音）から選びます。［🔊 聞く］で1回鳴らせます。エラーの音を鳴らすかどうかは実行バーの［アラーム音］、確認待ちは「音を鳴らす」で決めます |
| 確認されるまで音をくり返す | 知らせが消えるまで、決めた間隔（1〜30分）で音を鳴らし直します。「表示しない」のときは使えません |
| 👀 試しに表示する | いまの設定で表示してみます |

- はじめの設定は、エラーが「画面全体・赤・点滅・3分ごとにくり返す」、確認待ちが「画面の縁だけ・黄色・点滅・音なし」です。
- モニターが2台以上あれば、すべてのモニターに出します。
- 確認待ちのときは、確認のダイアログが知らせの手前に出ます。ダイアログのボタンを押すと、知らせも消えます。
- 知らせが出ているあいだは、予定（⏰）の実行は待ちます。画面の縁だけのときに［▶ 実行］を押すと、知らせは消えます。
- だれがいつ確認したかの目安として、ログに「確認してもらえたよ（14:05 から、12分たったよ）」のように残ります。
- 設定はこの PC だけのもので、`fujikyun_settings.json` に保存されます。

## 14. スケジュール（⏰ 予定）

いちばん上の段の **［⏰ 予定］** で、決まった時刻にマクロを自動で実行できます。次の予定はそのボタンの右に表示されます。

- **くり返し**: 毎日／平日（月〜金）／指定した日に1回
- **CSV**: 指定すると、その CSV を読み込んで全行を実行します。空欄なら1回だけ実行します。
- **ふじキュンを開いているとき**: ふじキュンが自分で時刻を見て実行します（予定の時刻から10分以内に始めます。過ぎていたらその日は実行しません）。
- **［🗓 Windowsに登録］**: Windows のタスクスケジューラに登録すると、ふじキュンを閉じていても、時刻にふじキュンを起動して実行します。タスクの名前は `FujikyunRPA_PS_` で始まり、「`fujikyun.ps1` を `-AutoRun <予定のID>` で起動する」内容です。「完了したら閉じる」にすると、最後まで完了したときだけ閉じます（エラーのときは画面を残します）。予定を削除するか［登録を解除］すると、タスクも消えます。
- 予定の一覧は `fujikyun_settings.json` に保存されます。

### 時刻以外のきっかけ（キー・ファイル・ウィンドウ）

予定の「きっかけ」で、時刻のほかに次の3つを選べます。どれも **ふじキュンを開いているあいだだけ** 見張ります（Windows への登録はできません）。

| きっかけ | 動き | マクロで使える値 |
| --- | --- | --- |
| ⌨ キーを押したとき | どの画面を使っていても、決めたキー（例 `Ctrl+Shift+1`）を押すとマクロを実行します。英字・数字は Ctrl か Alt と一緒に、F1〜F12 は単独でも使えます | — |
| 📂 フォルダにファイルが届いたとき | 見張るフォルダに、ファイル名のパターン（例 `*.csv`）に合う **新しいファイル** が来たら実行します（3秒ごとに見て、コピーが終わってから動きます）。「届いたファイルをそのままデータにして実行する」にすると、届いた CSV・Excel を読み込んで全行を実行します | `{{$きっかけのファイル}}`（届いたファイルのパス） |
| 🪟 ウィンドウが開いたとき | タイトルに決めた文字を含むウィンドウが **開いたとき** に実行します（開いたままのあいだはくり返しません） | `{{$きっかけのウィンドウ}}` |

- ふじキュンの画面でダイアログを開いているあいだや、別のマクロを実行中のときは、終わるまで待ちます（キーは、そのとき押した分は数えません）。
- 見張りを始めたときにもうあったファイルや、もう開いていたウィンドウでは動きません。
- 予定で動くときは、確認や質問のダイアログで止まらないように、CSV が読めないなどの問題があれば実行しません。

> ⚠ ロボットは画面を操作するので、実行する時刻に **PCの電源が入っていて、ログインしたまま、画面ロックされていない** 必要があります。Windows に登録したタスクも、ログインしているときだけ動きます。

## 15. 安全装置

| しくみ | 内容 |
| --- | --- |
| ウィンドウ見失い防止 | 対象ウィンドウが見つからないときは1秒おきに最大3回探し、だめならアラーム＋停止 |
| 自分への誤入力防止 | 入力先がふじキュン自身になりそうなときは、対象ウィンドウに戻すか、戻せなければ停止 |
| アラーム | 異常停止・タイムアウト時に、Windows のアラーム音（はじめは `Alarm01.wav`。［🚨 知らせ方］で変えられます）を約12秒鳴らします。鳴らせないときは Windows の警告音にします。［🔔］でテストできます |
| 画面で知らせる | 異常停止と確認待ちを、画面全体か画面の縁の色で知らせます（［🚨 知らせ方］） |
| 確認ポイント | CONFIRM で人の確認をはさめます。登録・送信などの前に入れるのがおすすめです |
| Esc で停止 | ふじキュンの画面で Esc を押すと止まります。ほかの画面が前にあるときは **Esc を約1秒長押し**（マクロの KEY {ESC} は一瞬なので反応しません） |
| 終わらない繰り返しの防止 | 繰り返しは上限回数、マクロの呼び出しは10段まで |
| 自動保存 | 編集のたびに一時ファイルへ保存。次回起動時に復元できます |
| エラー時の画面 | エラーで止まった瞬間の画面全体を `evidence\` に自動で保存 |
| パスワードを書かない | SECRET（🔑 パスワードを入力）は Windows の資格情報マネージャーから読むので、パスワードがマクロ・CSV・ログ・実行結果に残りません |

### パスワードの扱い（SECRET）

1. 「パスワードを入力」のステップを追加し、**登録名**（例 `基幹系`）を決めます。
2. **［🔑 登録・変更］** を押して、ユーザー名とパスワードを入れます。
3. 同じ画面で **入れてよい画面** を決めます。**［🎯 画面を指す（3秒）］** を押して、3秒以内にログインする画面をクリックすると、その画面のタイトルとプログラム（.exe の場所）が入ります。タイトルは、毎回変わらない一部だけに手で直せます。画面を指さないと保存できません。Windows の **資格情報マネージャー** に、`FujikyunRPA:登録名` という名前で保存されます。
4. 実行すると、いまの入力欄にパスワード（またはユーザー名）を打ち込みます。ログには「入力した」とだけ出て、値は出ません。

- **登録した画面にしか入力しません**。前にある画面のタイトルに登録した文字が入っていて、しかも登録したプログラム（同じ場所の .exe）の画面のときだけ打ち込みます。
- **パスワードは、パスワードの欄（入れた文字が ● になる欄）にしか入力しません**。前のステップでパスワードの欄を選んでおきます（例: 「欄に入力（名前で）」で欄を選ぶ）。ユーザー名はふつうの欄にも入れられます。
- 条件に合わないときは、何も打ち込まずに止まります。「エラー時の処理」でも受け止めません。取り込んだマクロが、メモ帳やふつうの欄にパスワードを打ち込んで読み取る、といった使い方を防ぐためです。

- 登録は、**その PC に、そのユーザーでサインインしたときだけ** 読めます。別の PC や別の人が使うときは、その人が自分で登録します（マクロを書き出しても、パスワードは一緒に渡りません）。
- パスワードを変えたら、もう一度［🔑 登録・変更］で登録し直します。登録を消すときも同じ画面の［登録を消す］を使います。Windows の「資格情報マネージャー」（コントロール パネル）からも確認・削除できます。
- 入力はキーを1つずつ送る方法なので、日本語入力（IME）はオフにしておいてください。

## 20. マクロファイルの形式

`fujikyun_macros.json`（と書き出したマクロ）は、次の形の JSON です。ふつうは編集画面だけで作れるので、読む必要はありません。

```json
{
  "version": 27,
  "macros": [
    {
      "id": "a1b2c3d4",
      "name": "見本",
      "targetWindow": "メモ帳",
      "steps": [
        { "cmd": "CSV", "val": "1", "label": "CSV 1列目「氏名」を貼付" },
        { "cmd": "WINDOW_CHECK", "val": "{\"title\":\"エラー\",\"key\":\"{ENTER}\",\"mode\":\"SKIP\"}", "label": "…" },
        { "cmd": "GROUP_START", "val": "保存", "label": "保存", "when": "last" }
      ]
    }
  ]
}
```

- `val` は、**設定が1つのコマンドはその値そのもの**（KEY・TEXT・CSV・COPY・WAIT・CONFIRM・CLICK_NAME・SWITCH・RUN・GROUP_START・COMMENT など）、**設定が2つ以上のコマンドは JSON**（WAIT_FOR・WINDOW_CHECK・CLICK_POS・CLICK_IMG・SCREENSHOT・CLICK_TEXT・READ_TEXT・MAIL・流れ・変数のコマンド）です。カンマ区切りは使わないので、タイトルやパスにカンマが入っていても大丈夫です。
- `when`（グループの実行タイミング: `first` / `last`）と `disabled`（無効化）、`breakpoint`（止める所）は、必要なときだけ付きます。
- `version` はデータの版です。この版（27）より新しい版で作られたファイルは、上書きする前に確認が出ます。古い版（26 以前）のコマンド名・値の形には対応していません。

## 21. 効果の測りかた（📈 効果）

ふじキュンは、実行のたびに **どのマクロで何件を処理したか・どれだけ時間がかかったか・人がどれだけ付いていたか** を記録します（`fujikyun_runs.csv`）。いちばん上の段の **［📈 効果］** を押すと、この記録から、ロボットが引き受けた手作業の時間（削減時間）を、マクロごと・月ごとに一覧にします。

### はじめにすること

1. ［📈 効果］を開きます。一度でも実行したマクロが一覧に出ます。
2. 一覧でマクロを選び、下の **「1件を手でやると ○ 分」** に、そのマクロの作業を **人が手でやったときの1件あたりの時間** を入れて［決める］を押します。
   - 1件は CSV の1行です（CSV を使わないマクロは1回の実行）。
   - 何件か手でやってストップウォッチで計り、その平均を入れるのがおすすめです。小数も使えます（例: `4.5`）。
3. 人件費に換算したいときは、上の **「時間単価」** に1時間あたりの金額（円）を入れます。

手作業の時間と時間単価は、`fujikyun_settings.json` にマクロごとに保存されます。あとから直すと、過去の分も直した値で計算し直します。

### 一覧の見かた

| 列 | 内容 |
| --- | --- |
| 実行回数 | その期間に実行した回数（試しの実行は数えません） |
| 完了件数・エラー件数・エラー率 | 最後まで済んだ行の数、エラーで止まった行の数、処理した行のうちエラーで止まった行の割合（スキップした行は、どちらにも数えません） |
| ロボットの実行時間 | ロボットが動いていた時間の合計 |
| 人の対応時間 | 実行中に人が付いていた時間（確認ポイント・値の入力を待っていた時間、一時停止していた時間） |
| エラーで止まっていた時間 | エラーで止まってから、知らせ（［🚨 知らせ方］）を確認するまでの時間。人が気づくまでの待ちなので、削減時間からは引きません |
| 手作業の時間 | 上で決めた1件あたりの分。決めていないマクロは空で、削減時間を計算しません |
| **削減時間** | **完了件数 × 手作業の時間 − 人の対応時間**（分） |
| 換算額 | 削減時間 × 時間単価（時間単価を入れたとき） |
| 作成・手直しの時間 | その期間にマクロを編集していた時間。マクロを作る手間として、削減時間とくらべるのに使います |

- **期間** で、月ごとか全期間かを選べます。
- ［📋 表をコピー］で Excel に貼り付けられる形でコピー、［💾 CSVに保存］で `fujikyun_effect_年月.csv` に保存できます。報告の資料に使えます。
- **試しの実行**（［▶ ここから］［この1つだけ］［⏯ 1ステップずつ］）は数えません。［▶ 実行］・予定・きっかけで動かした実行だけを数えます。
- **作成・手直しの時間** は、マクロを編集した操作と操作のあいだの時間を足したものです。5分より長く手が止まっていた間は、休みとして数えません（この5分は、ふじキュンで決めた目安です）。

### 記録のファイル

| ファイル | 1行の中身 |
| --- | --- |
| `fujikyun_runs.csv` | 開始・終了日時、マクロ、起動（手動・予定・きっかけ・試し）、結果、処理した行・完了・スキップ・エラーの数、エラー行の再実行かどうか、実行時間、人の対応時間、エラーで止まっていた時間 |
| `fujikyun_edits.csv` | 日付、マクロ、編集時間 |

どちらも Excel でそのまま開けます。マクロの名前と件数・時間だけで、CSV の中身（住民の情報など）は入りません。自動では消えないので、いらなくなった古い行は Excel で消してかまいません。
