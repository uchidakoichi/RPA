# ふじキュン♡のRPAマクロビルダー 操作マニュアル

Windows だけで動く RPA（パソコン作業の自動化）ツールです。インストール不要で、`fujikyun_rpa_builder.hta` をダブルクリックすると起動します。ネットワークにはつながりません。

- はじめての方は [チュートリアル](tutorial.md) から読むのがおすすめです。
- お手本マクロの解説は [テンプレート解説](templates.md) にあります。
- 困ったときは [Q&A](faq.md) を見てください。

## 1. 動作環境と置き場所

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11（HTA が動くこと） |
| 必須 | なし（Windows 標準の機能だけで動きます） |
| PowerShell | `CLICK`・`CLICK_POS`・`CLICK_IMG`・`SCREENSHOT`・座標や画像の取得・ウィンドウ一覧・アラームで使います。PowerShell が使えない端末でも、キーボード操作中心のマクロは動きます |
| 置き場所 | **書き込みできるフォルダ**に置いてください（例: `C:\RPA作業\` やドキュメント）。マクロやログは HTA と同じフォルダに保存されます |

GitHub などからダウンロードしたファイルは、Windows が「インターネットから来たファイル」の印を付けることがあります。そのまま開くと動かないときは、ファイルを右クリック →［プロパティ］→［全般］タブの **［許可する］（ブロックの解除）** にチェック →［OK］してから起動してください。

起動したら、まず **［🩺 環境チェック］** を押して、その端末で使える機能を確かめましょう（[14章](#14-環境チェック)）。

```

│ マクロ  [選択▼] ＋新規 ✎名前変更 ⧉複製 🗑削除 📚テンプレート 📤書出 📥取込 │
│         対象ウィンドウ [      ] 🔍一覧                                      │
│ CSV     [パス          ] 📂参照 📥読込 □1行目は見出し [文字コード▼]          │
│ 追加    ⌨KEY 📝TEXT 📄CSV 📋COPY_SAVE ⏳WAIT 👀WAIT_FOR ⚠IF ✋CONFIRM …     │
│ 編集    ↩️ ↪️ [履歴▼] ▲ ▼ ⧉複製 ⊘無効化 ▼全展開 ▶全折りたたみ              │
├──────────────────────────────────────────┤
│  マクロのブロック表示エリア（ウィンドウに合わせて伸び縮みします）          │
├──────────────────────────────────────────┤
│ ▶実行 ⏸一時停止 ⏹停止 開始行 終了行 間隔 □アラーム 🔔 □毎ステップ前面化   │
│ □完了音 ↓エラー行をCSV保存 ↓実行結果CSV 🩺環境チェック        進み具合     │
│ ログ                                                                          │
└──────────────────────────────────────────┘
```

- **保存状態**: 「● 未保存の変更あり」のときは、編集内容が一時ファイルにだけ保存されています。［💾 本番ファイルに保存］（Ctrl+S）で確定します。
- **ブロック**: 1つのブロックが1つの命令（コマンド）です。左端の色でコマンドの種類が分かります。
  - 青: 入力（KEY・TEXT・CSV・COPY_SAVE）
  - 橙: 流れ（WAIT・WAIT_FOR・IF・CONFIRM）
  - 紫: ウィンドウ（SWITCH・RUN・SCREENSHOT）
  - 緑青: マウス（CLICK・CLICK_POS・CLICK_IMG）
  - 茶: グループ
  - 緑: コメント

## 3. 基本の考え方：CSVの1行＝1回

ふじキュンは **マクロ（手順）を、CSVの行の数だけくり返します**。

```
CSV                        マクロ
氏名,電話番号               ① SWITCH 入力画面へ
見本 太郎,000-0000-0001  →  ② CSV 1列目を貼付
試験 花子,000-0000-0002  →  ③ KEY  Tab
練習 一郎,000-0000-0003  →  ④ CSV 2列目を貼付
                            ⑤ KEY  Enter
```

- 「1行目は見出し」にチェックがあると、1行目は見出しとして扱い、2行目からくり返します（初期値はチェックあり）。
- CSV を読み込まずに実行すると、マクロを **1回だけ** 実行します（CSV コマンドは空欄扱い）。
- 文字コードは自動判定（UTF-8 → だめなら Shift_JIS）です。Excel で「CSV（コンマ区切り）」で保存したファイルもそのまま読めます。

## 4. マクロの作成と編集

### 作り方は3通り

1. **［📚 テンプレート］から作る**（おすすめ）: お手本を選んで［✨ 作る］。見本CSVも自動で読み込まれます。
2. **［＋ 新規］で空のマクロから作る**: 「追加」の行のボタンでコマンドを足していきます。
3. **［📥 取込］で同僚が書き出したマクロを取り込む**（[13章](#13-マクロの共有書出取込)）。

### ブロックの操作

| したいこと | 操作 |
| --- | --- |
| 選ぶ | 1回クリック（青枠になります）。次に追加するコマンドは **選んだブロックの後ろ** に入ります |
| 編集する | ダブルクリック、右端の ✎、または Enter |
| 削除する | 右端の ✕、または Delete。グループは「中身ごと削除」か「枠だけ解除」を選べます |
| 並べ替える | ドラッグ＆ドロップ（青い線の位置に入ります）、または ▲▼（Alt+↑↓） |
| 複製する | ⧉ 複製（Ctrl+D）。グループなら中身ごと複製します |
| 一時的に止める | ⊘ 無効化（Ctrl+/）。薄く表示され、実行時は飛ばされます。もう一度押すと元に戻ります |
| 元に戻す | ↩️（Ctrl+Z）／ やり直し ↪️（Ctrl+Y）。履歴▼から好きな時点にも戻れます（最大30件） |

### グループ

`GROUP` を追加すると「グループ開始〜グループ終了」がセットで入ります。

- 中のブロックは字下げされ、左の ▼/▶ で折りたためます。
- グループ開始を無効化すると、**グループの中身がまるごと飛ばされます**。
- **実行タイミング** を設定できます。
  - 毎行（ふつう）
  - **最初の1行だけ**: アプリの起動、ログイン、画面を開くなどの「準備」に
  - **最後の1行だけ**: 保存、閉じるなどの「後片付け」に

## 5. コマンド一覧

「値（val）」はマクロファイル（JSON）に保存される形です。編集ダイアログでは項目ごとに入力できるので、書式を覚える必要はありません。

### 入力

| コマンド | 値 | 動き |
| --- | --- | --- |
| **KEY** キー送信 | 送るキー（例 `{TAB}`） | キーボード操作を送ります。書き方は [7章](#7-キーの書き方sendkeys) |
| **TEXT** 文字列貼付 | 文字列（差し込み可） | クリップボード経由で貼り付けます（Ctrl+V）。日本語入力がONでも化けません |
| **CSV** CSV列を貼付 | 列番号（1始まり） | いま処理中の行の、指定した列の値を貼り付けます。空欄なら何もしません |
| **COPY_SAVE** 値をコピーして記録 | 項目名 | いま選ばれている文字を Ctrl+C でコピーして記録します。記録した値は **実行結果CSV の列** になり、あとの TEXT で `{{COPY:項目名}}` として貼り付けられます |

> 💡 TEXT・CSV は「貼り付け」なので、入力欄にもともと文字があると後ろに追加されます。上書きしたいときは直前に `KEY ^a`（全選択）を入れます。

### 流れの制御

| コマンド | 値 | 動き |
| --- | --- | --- |
| **WAIT** 待機 | ミリ秒（1000＝1秒） | 指定時間待ちます |
| **WAIT_FOR** ウィンドウ出現待ち | `タイトル,押すキー,タイムアウト秒` | 指定タイトルのウィンドウが出るまで1秒ごとに見張り、出たらキーを押して次へ。時間切れならアラームを鳴らして停止します |
| **IF** 条件分岐 | `タイトル,押すキー,モード` | そのウィンドウが **いま** 出ているかを確認。出ていたらキーを押して、モードに従います。出ていなければ何もせず次へ |
| **CONFIRM** 確認ポイント | メッセージ（差し込み可） | ロボットを止めてメッセージを表示し、人の判断を待ちます |

IF のモード:

| モード | 動き | 使いどころ |
| --- | --- | --- |
| `STOP` | アラームを鳴らして緊急停止 | 想定外のエラー |
| `SKIP` | この行を打ち切り、エラー行として記録して次の行へ | 「該当なし」など、飛ばせばよいもの |
| `CONTINUE` | キーを押してそのまま続行 | ときどき出るお知らせ・上書き確認などを閉じる |

CONFIRM のボタン:

- **▶ 続行**: 対象ウィンドウに戻って続きを実行
- **⏭ この行をスキップ**: この行を打ち切って次の行へ
- **⏹ 停止**: 実行をやめる（Esc でも停止。確認ポイントの表示中はふじキュンが前面にあるので、そのまま Esc で止まります）

確認ポイントの表示中に、対象の画面をクリックしてカーソルを置いてから［続行］することもできます（テンプレートではこの方法で「最初の入力欄」を合わせています）。

### ウィンドウ

| コマンド | 値 | 動き |
| --- | --- | --- |
| **SWITCH** ウィンドウ切替 | ウィンドウ名（差し込み可） | そのウィンドウを前面にして、以降の操作先にします |
| **RUN** アプリ起動 | コマンド（差し込み可） | アプリやファイルを開きます。Windows のコマンドも実行できます（例: `cmd /c mkdir "C:\RPA作業\{{1}}"`）。スペースを含むパスは `"` で囲みます |
| **SCREENSHOT** 画面を撮影 | `ファイル名,範囲` | 画面を PNG で保存します。範囲は `WINDOW`（前面のウィンドウ）か `FULL`（全モニター）。保存先は `evidence\日付\` で、ファイル名の後ろに時刻が付きます |

### マウス（画面認識）

| コマンド | 値 | 動き |
| --- | --- | --- |
| **CLICK** オブジェクト認識 | ボタン等の表示名 | 名前でボタンを探して押します（第一推奨） |
| **CLICK_POS** 座標認識 | `X,Y` | 画面の座標をクリックします。編集画面の［📍 数秒後のマウス位置を取得］で座標を取れます |
| **CLICK_IMG** 画像認識 | `画像パス,しきい値` | 画面から画像と同じ模様を探してクリックします。［📷 5秒後のマウス周辺を切り取り］で見本画像を作れます |

詳しくは [9章](#9-画面認識の3つの方法)。

### 整理

| コマンド | 値 | 動き |
| --- | --- | --- |
| **GROUP** | グループ名 | 手順をまとめます（[4章](#グループ)） |
| **COMMENT** | メモ | 実行時は何もしません。手順の説明を書いておきましょう（緑の斜体で表示） |

## 6. 差し込み

TEXT・RUN・SWITCH・WAIT_FOR・IF・CONFIRM・SCREENSHOT の値の中で `{{ }}` を使うと、実行時に値が入ります。編集ダイアログの［＋ 差し込みを追加 ▼］からも選べます。

| 書き方 | 入る値 | 例 |
| --- | --- | --- |
| `{{1}}` `{{2}}` … | CSV の1列目、2列目… | `見本 太郎` |
| `{{氏名}}` | CSV の見出しが「氏名」の列 | `見本 太郎` |
| `{{ROW}}` | CSV の行番号（データの1行目＝1） | `3` |
| `{{ROW+1}}` `{{ROW-2}}` | 行番号に足し引き | Excel のセル番地 `A{{ROW+1}}` → `A4` |
| `{{COPY:伝票番号}}` | この行で COPY_SAVE した値 | `R08-00123` |
| `{{TODAY}}` | 今日 | `2026/09/30` |
| `{{TODAY_JP}}` | 今日 | `2026年9月30日` |
| `{{WAREKI}}` | 今日（和暦） | `令和8年9月30日` |
| `{{WAREKI_YEAR}}` | 和暦の年 | `令和8年` |
| `{{YYYYMMDD}}` | 今日 | `20260930` |
| `{{NOW}}` | 時刻 | `14:05` |
| `{{TIMESTAMP}}` | 日時（ファイル名向け） | `20260930_140512` |
| `{{YEAR}}` `{{MONTH}}` `{{DAY}}` | 年・月・日 | `2026` `9` `30` |

- 見出し名は **完全一致** です（前後の空白は無視）。分からない差し込みはそのまま残り、ログに警告が出ます。
- CSV の見出しと同じ名前なら、**見出しが優先** されます（例: 見出しが「DAY」の列があれば `{{DAY}}` はその列の値）。数字だけの見出しは `{{列番号}}` で指定してください（`{{2026}}` は「2026列目」と読まれます）。
- 和暦は令和（2019年5月1日〜）・平成・昭和に対応しています。元年は「元年」と表示します。

## 7. キーの書き方（SendKeys）

KEY コマンドや、WAIT_FOR・IF の「押すキー」は、Windows の SendKeys の書き方です。

| 書き方 | キー | 書き方 | キー |
| --- | --- | --- | --- |
| `{TAB}` | Tab | `+{TAB}` | Shift+Tab |
| `{ENTER}` | Enter | `{ESC}` | Esc |
| `{SPACE}` | スペース | `{BS}` | BackSpace |
| `{DELETE}` | Delete | `{UP}` `{DOWN}` `{LEFT}` `{RIGHT}` | 矢印 |
| `{HOME}` `{END}` | Home / End | `{PGUP}` `{PGDN}` | PageUp / PageDown |
| `{F1}`〜`{F12}` | ファンクションキー | `{TAB 3}` | Tab を3回（回数指定） |
| `^a` | Ctrl+A | `^{HOME}` | Ctrl+Home |
| `%{F4}` | Alt+F4 | `%y` | Alt+Y（「はい(Y)」ボタンなど） |

- 記号の意味: `^` = Ctrl、`+` = Shift、`%` = Alt
- `+` `^` `%` `~` `(` `)` `{` `}` `[` `]` を文字として送るときは `{+}` のように `{ }` で囲みます。
- 文字を入力したいときは KEY ではなく **TEXT** を使ってください（日本語入力の影響を受けません）。

## 8. ウィンドウ名の合わせ方

対象ウィンドウ・SWITCH・WAIT_FOR・IF のタイトルは、ウィンドウのタイトルバーの文字を次の順で探します。

1. 完全に一致するもの
2. **先頭** が一致するもの
3. **末尾** が一致するもの

例: Excel のタイトル「台帳.xlsx - Excel」は、`台帳.xlsx`（先頭）でも `Excel`（末尾）でも見つかります。途中の文字だけ（`xlsx`）では見つかりません。

［🔍 一覧］を押すと、いま開いているウィンドウのタイトル一覧から選べます（PowerShell を使います）。

**対象ウィンドウ** を設定すると、各行の最初にそのウィンドウを前面にします。空欄の場合は、実行開始から3秒待つので、その間に入力先をクリックするか、マクロの中で RUN・SWITCH してください。

## 9. 画面認識の3つの方法

ボタンを押す方法は3つあります。上から順に試すのがおすすめです。

| 方法 | 強み | 弱み |
| --- | --- | --- |
| **CLICK** オブジェクト認識 | 画面の位置や大きさが変わっても動く。いちばん確実 | 名前を持たない部品（独自描画のボタン、Citrix/RDP の中）には効かない |
| **CLICK_POS** 座標認識 | どんな画面でも使える | ウィンドウの位置・大きさ・画面の拡大率が変わるとずれる |
| **CLICK_IMG** 画像認識 | Citrix/RDP の中など、中身が見えない画面でも使える | 色やテーマが変わると見つからない。数秒かかる |

### CLICK のコツ
- ボタンに表示されている文字（「登録」「OK」など）を **完全一致** で指定します。
- 対象ウィンドウ（または SWITCH したウィンドウ）とフォーカスのあるウィンドウの中を探します。

### CLICK_POS のコツ
- 編集画面の［📍 数秒後のマウス位置を取得］を押し、3秒以内に目的の場所へマウスを置くと座標が入ります。
- 対象ウィンドウは **最大化** して使うとずれにくくなります。

### CLICK_IMG のコツ
- 編集画面の［📷 5秒後のマウス周辺を切り取り］を押し、5秒以内に対象の画面を前に出して、ボタンの真ん中にマウスを置きます。`rpa_images` フォルダに PNG が保存されます。
- 切り取る範囲は **ボタンの特徴的な部分だけ**（文字＋枠の一部など）が見つかりやすいです。背景が大きく入ると失敗しやすくなります。
- しきい値 0.9 は「90%以上のピクセルが一致したらクリック」の意味です。見つからないときは 0.85 などに下げます。低くしすぎると別の場所を押す恐れがあります。
- 見つからないときは1秒おきに3回まで探し、それでもだめならアラームを鳴らして止まります。
- 画像のパスが相対パス（例 `rpa_images\img_….png`）なら、HTA のフォルダを基準にします。フォルダごとコピーすれば別の PC でも使えます。

## 10. 実行

| 項目 | 説明 |
| --- | --- |
| ▶ 実行 | 選択中のマクロを、CSV の開始行〜終了行について実行します |
| 開始行・終了行 | データ行の番号（見出しを除いて1から）。**試すときは両方1にして1件だけ** |
| 間隔 | ステップとステップの間の待ち時間（ミリ秒）。画面が追いつかないときは増やします |
| ⏸ 一時停止 | 次のステップの前で止まります。［▶ 再開］で対象ウィンドウに戻ってから続きを実行します |
| ⏹ 停止 | すぐ止めます。ふじキュンの画面で **Esc** を押しても止まります。ロボットが入力中で別の画面が前にあるときは、**Esc を約1秒長押し** すると、どの画面からでも止まります |
| □ 毎ステップ前面化 | 入力の前に毎回、対象ウィンドウを前面にします。途中で別の画面が割り込む環境で ON にします |
| □ 完了音 | 全行が終わったら音で知らせます |

実行中のブロックは黄色で表示されます。実行中はマクロを編集できません。

### 実行結果CSV
［↓ 実行結果CSV］を押すと `gprime_result.csv` を保存します。
- 元のCSVの列 ＋ COPY_SAVE で記録した値 ＋ SCREENSHOT の保存先 ＋ **実行結果**（完了／スキップ／エラー／中断）＋ 備考 ＋ 元データ行No ＋ 開始日時
- Excel で開いて「実行結果」でフィルターすると、やり直しが必要な行がすぐ分かります。

### エラー行CSV
［↓ エラー行をCSV保存］を押すと `gprime_error_list.csv` を保存します。元データと同じ列の並びなので、**直してそのまま読み込めば、エラーになった行だけ再実行** できます。

- エラー行CSV（と実行結果CSV）には「元データ行No」列があります。「1行目は見出し」を ON にしてこの列があるCSVを実行すると、`{{ROW}}` やログの行番号は **元のCSVの行番号** になるので、`A{{ROW+1}}` のようなセル番地もずれません。
- IF の SKIP 以外のエラー（IF の STOP、タイムアウト、ウィンドウが見つからない、クリック失敗など）は **実行そのものが止まる**ので、その後ろの行はまだ処理されていません。エラー行を直したら、元のCSVで **開始行** をその次の行にして続きを実行してください。

## 11. 安全装置

| しくみ | 内容 |
| --- | --- |
| ウィンドウ見失い防止 | 対象ウィンドウが見つからないときは1秒おきに最大3回探し、だめならアラーム＋停止 |
| 自分への誤入力防止 | 入力先がふじキュン自身になりそうなときは、対象ウィンドウに戻すか、戻せなければ停止 |
| アラーム | 異常停止・タイムアウト時に鳴ります。PowerShell → Windows Media Player 部品 → 音声合成 の順に、鳴らせる方法を自動で選びます。［🔔］でテストできます |
| 確認ポイント | CONFIRM で人の確認をはさめます。登録・送信などの前に入れるのがおすすめです |
| Esc で停止 | ふじキュンの画面で Esc を押すと止まります。ほかの画面が前にあるときは **Esc を約1秒長押し**（PowerShell が使える端末のみ。マクロの KEY {ESC} は一瞬なので反応しません） |
| 自動保存 | 編集のたびに一時ファイルへ保存。次回起動時に復元できます |

## 13. マクロの共有（書出・取込）

- **［📤 書出］**: 選択中のマクロを `macro_export\マクロ名.json` に保存します。同じ名前のファイルがあるときは、上書きせずに `マクロ名 (2).json` のように番号を付けます。
- **［📥 取込］**: 書き出した JSON を選ぶと、マクロが追加されます（今あるマクロは消えません）。

CLICK_IMG の画像を使っているマクロを渡すときは、`rpa_images` フォルダも一緒に渡してください。

## 14. 環境チェック

［🩺 環境チェック］を押すと、その端末で使える機能を調べて一覧にします。

| 項目 | NG のときに使えない機能 |
| --- | --- |
| WScript.Shell / FileSystemObject | ほぼすべて（HTA として起動しているか確認） |
| 作業フォルダへの書き込み | マクロの保存、各種CSV・画像の保存 |
| クリップボード | TEXT・CSV・COPY_SAVE |
| PowerShell の起動・実行 | CLICK・CLICK_POS・CLICK_IMG・SCREENSHOT・座標/画像の取得・ウィンドウ一覧・アラーム（PowerShell版） |
| 言語モードが FullLanguage 以外 | C# を使う CLICK_POS・CLICK_IMG・SCREENSHOT など |
| C# のその場コンパイル | CLICK_POS・CLICK_IMG・SCREENSHOT・座標/画像の取得 |
| Windows Media Player 部品 / 音声合成 | アラームの予備手段 |

PowerShell が使えない端末でも、**KEY・TEXT・CSV・WAIT・WAIT_FOR・IF・SWITCH・RUN・CONFIRM・COPY_SAVE** は動きます。キーボード操作（Tab 移動など）中心でマクロを組めば、自動化できる作業はたくさんあります。

［結果をログにコピー］を押すと、ログ欄に結果が残るので、問い合わせのときに便利です。
