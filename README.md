# ふじキュン♡のおしごとロボット

Windows のオフライン環境で動く RPA（パソコン作業の自動化）ツールです。CSV のデータを、Excel・Word・文書起案システム・財務会計システム・グループウェア・福祉・税・住基システムなどへ自動で入力します。

- インストール不要: `fujikyun.bat` をダブルクリックするだけ
- 外部ソフト不要: Windows に最初から入っている **Windows PowerShell 5.1 ＋ Windows Forms** だけで動作
- 初心者向け: 381種類のテンプレートと見本CSVを内蔵
  - 職場別: 職場の共通事務・消防局／消防署・保育園／こども園・小学校（先生の校務）・学校／教育委員会・市民病院（事務）・保健センター・上下水道・図書館／公民館／施設
  - 道具別: ファイル・フォルダ操作・Excel・Word・PowerPoint・PDF／印刷・ブラウザ・メール・変数／繰り返し／分岐・文字認識
  - システム別: 文書起案・財務会計・グループウェア・福祉・生活保護・国保／介護保険／税務／住民情報／住民基本台帳／収納管理／滞納管理／子ども・子育て／後期高齢者医療／国民年金・庶務事務・人事給与・契約・入札・戸籍・選挙
- 読みやすさ: 文字の大きさを 90%〜200% で変更、ウィンドウの位置・大きさ・左右の境目を記憶。［📖 説明書］と F1 で、説明書の該当箇所をブラウザで開ける

## ダウンロードと起動

1. リポジトリ直下の次の5つを、ローカルの**同じフォルダ**に置きます。
   - `fujikyun.bat`・`fujikyun.ps1`・`fujikyun_ja.json`・`fujikyun_commands.json`・`fujikyun_templates.json`

   自治体セキュリティクラウドのダウンロード機能では**ダウンロードしないでください**（ファイルが壊れることがあります）。GitHub で RAW 表示したコードを丸ごとメモ帳などに貼り付け、このファイル名で保存します。**JSON は文字コード「UTF-8」で保存**してください。
2. `fujikyun.bat` をダブルクリックで起動し、**［🩺 環境チェック］** で使える機能を確認します。
3. **［📚 テンプレート］** からお手本マクロを作って、動かしてみましょう。

詳しくは [準備](docs/src/setup.md) を見てください。

## 主な機能

コマンドは［追加］の行に7つの分類で並んでいます（全コマンドの説明は [操作マニュアル 5章](docs/src/manual.md#5-コマンド一覧)）。

| 分類 | コマンド |
| --- | --- |
| 入力 | キー送信（KEY）・文字列貼付（TEXT）・CSV列を貼付（CSV）・コピーして変数へ（COPY）・欄に入力（名前で）（FIELD_SET）・パスワードを入力（SECRET：Windows の資格情報マネージャーから） |
| 待つ・確かめる | 待機（WAIT）・ウィンドウ出現待ち（WAIT_FOR）・ウィンドウ検知（WINDOW_CHECK）・確認ポイント（CONFIRM） |
| クリック・読み取り | 名前で（CLICK_NAME）・文字で（CLICK_TEXT／OCR）・画像で（CLICK_IMG）・座標で（CLICK_POS）クリック、文字を読み取る（READ_TEXT／OCR）・欄の値を読む（名前で）（FIELD_GET）・表を読み取ってCSVに保存（TABLE_READ） |
| アプリ・画面 | ウィンドウ切替（SWITCH）・アプリ起動（RUN）・画面を撮影して保存（SCREENSHOT）・メール（MAIL：Outlook／mailto） |
| 流れ | 繰り返し（LOOP_START）・抜ける／次へ（BREAK／CONTINUE）・もし〜なら／そうでなければ（IF_START／ELSE）・エラー時の処理（TRY_START）・うまくいくまでやり直す（RETRY_START）・マクロの呼び出し／戻る（CALL_MACRO／RETURN） |
| 変数・データ | 変数に値を入れる・計算（SET_VAR）・文字の加工14種類（STR_OP）・実行中の入力（ASK）・結果に記録（RECORD）・Excelのセルを画面を開かずに読み書き（EXCEL_READ／EXCEL_WRITE） |
| 整理 | グループ（最初の1行だけ／最後の1行だけ も指定可）・コメント |

そのほか:

- 差し込み: `{{氏名}}` `{{1}}` `{{$変数}}` `{{ROW+1}}` `{{WAREKI}}` `{{TODAY}}` など
- 作りながら試す: 止める所（ブレークポイント）・1ステップずつ実行・選んだステップから実行・選んだステップだけ実行
- 部品を指す: 入力欄・ボタン・表をマウスで指すと名前が入り、［🔍 見つかるか試す］で実行と同じ探し方を確かめられる
- 画面操作の記録: ふつうに操作するだけで、クリック・キー・文字入力・ウィンドウ切替をコマンドに変換（名前のある入力欄への入力は「欄に入力（名前で）」に）
- Excel のブックをそのままデータに: CSV の欄でブックを選ぶと1枚目のシートを読み込む
- スケジュール: 決まった時刻（毎日・平日・指定日）に自動で実行。Windows のタスクスケジューラにも登録できる。キーを押したとき・フォルダにファイルが届いたとき・ウィンドウが開いたときにも実行できる
- 変数ウォッチ: 実行中の変数・繰り返しの回数・この行のCSVの値をリアルタイムで表示
- 安全装置: Esc で停止（ふじキュンの画面で押す／どの画面でも約1秒長押し）、ウィンドウ見失い時の自動停止、アラーム、確認ポイント、1件テスト
- 結果の記録: 実行結果CSV、エラー行CSV（直して再実行）、画面の証跡保存、エラーで止まった瞬間の画面の自動保存
- 編集: ドラッグ＆ドロップ、ブロックの折りたたみ、無効化、元に戻す（30件）、自動保存、マクロの書出・取込

## ドキュメント（ブラウザで読む説明書）

- ［📖 説明書］や F1 で開く説明書は、ふじキュンのフォルダの中の `docs` フォルダに置きます。
  次の7つを、コードと同じく GitHub で RAW 表示して丸ごとメモ帳などに貼り付け、このファイル名で、**文字コード「UTF-8」で保存**します。
  - `docs/` の `index.html`・`tutorial.html`・`manual.html`・`templates.html`・`faq.html`・`setup.html`・`changes.html`（7つ）

  自治体セキュリティクラウドのダウンロード（無害化）を通すと、HTML の中の仕組み（スクリプトやリンク）が消されて、「…を開きます。」と出るだけになります。HTML も**ダウンロードしないでください**。
  7つとも置くと、`docs\index.html` をダブルクリックして、ネット接続なしで読めます（`index.html` が説明書の本体で、ほかの6つは `index.html` の該当ページを開くためのファイルです）。
- ダウンロードできる環境なら、**[dist/fujikyun_docs_samples.zip](dist/fujikyun_docs_samples.zip)** に説明書（HTML）と見本CSVをまとめています。展開して `docs\index.html` をダブルクリックします。
- GitHub 上で読む場合: [チュートリアル](docs/src/tutorial.md)・[テンプレート解説](docs/src/templates.md)・[操作マニュアル](docs/src/manual.md)・[Q&A](docs/src/faq.md)

## フォルダ構成

| パス | 内容 |
| --- | --- |
| `fujikyun.bat`・`fujikyun.ps1`・`fujikyun_ja.json`・`fujikyun_commands.json`・`fujikyun_templates.json` | ツール本体（利用者に必要なのはこの5つだけ） |
| `check/` | 事前チェックツール（この端末でふじキュンが動くかを調べる） |
| `src/`・`gui/`・`build/`・`tests/` | 保守用: ソース・組み立て・テスト（説明は [DEVELOP.md](DEVELOP.md)） |
| `samples/` | テンプレート用の見本CSV（すべて架空のデータ） |
| `docs/*.html` | ブラウザで読むドキュメント（`docs/src/*.md` から生成） |
| `docs/src/` | ドキュメントの原稿（Markdown） |
| `dist/fujikyun_docs_samples.zip` | ドキュメント（HTML）と見本CSVのまとめ |
| `build/Build-FujiTemplateDoc.ps1` | 保守用: `fujikyun_templates.json` から `samples/` と `docs/src/templates.md` を生成 |
| `tools/build_docs.js` | 保守用: `docs/src/*.md` から `docs/*.html` と zip を生成（Node.js が必要。利用者には不要） |
